¡Bienvenido al wiki de Basis!

Esta página te ayudará a proporcionar los pasos mínimos necesarios para poner en marcha un proyecto Basis, incluyendo guías para crear bundles de assets de Avatar y World.

## Requisitos del sistema actuales

https://docs.unity3d.com/Manual/system-requirements.html

## Instalar Unity

- Hub - https://unity.com/download
- Standalone - https://unity.com/releases/editor/archive

### Versiones de Unity compatibles

Según la rama utilizada, por favor observa la versión del editor Unity sobre la que se construye el framework:

✓ [Developer](https://github.com/BasisVR/Basis/blob/developer/Basis/ProjectSettings/ProjectVersion.txt#L1)  
✓ [Long-Term-Support](https://github.com/BasisVR/Basis/blob/long-term-support/Basis/ProjectSettings/ProjectVersion.txt#L1)

### Módulos adicionales de Unity

Añade los siguientes módulos a través de la pantalla "Añadir módulos" al instalar la versión del editor Unity:

```ts tab="Windows"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (Mono) 
✓ Mac Build Support (Mono)
✓ Windows Build Support (IL2CPP)
```

```ts tab="Mac"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (Mono)
✓ Mac Build Support (IL2CPP)
✓ Windows Build Support (Mono)
```

```ts tab="Linux"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (IL2CPP)
✓ Mac Build Support (Mono)
✓ Windows Build Support (Mono)
```

<Callout type="info">
Incluso si solo estás creando contenido generado por el usuario para la creación de Avatars y Worlds, seguirás necesitando estos módulos adicionales para que el contenido esté disponible en estas plataformas.
</Callout>

<Callout type="info">
Si ya tienes instalada la versión correcta de Unity pero la opción "Añadir módulos" no está disponible, probablemente fue instalada externamente desde Unity Hub. Por favor, reinstala la versión correcta de Unity desde Unity Hub.
</Callout>

## Obtener el framework Basis

### Git

Puedes directamente [clonar](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) las ramas `developer` o `long-term-support` en https://github.com/BasisVR/Basis o [hacer un fork](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo) en tu propio repositorio local. El proyecto de Unity es la subcarpeta `Basis` dentro del clon (`Basis/Basis`); consulta [Abrir el proyecto en Unity Hub](#opening-the-project-in-unity-hub) más abajo.

### Descarga directa de ZIP

Para quienes deseen prescindir de Git:

- Selecciona el menú desplegable "Code" en la parte superior derecha y luego Descargar ZIP.
- Descomprime el ZIP en cualquier carpeta que desees. Se descomprime en una carpeta con el nombre de la rama, por ejemplo `Basis-developer`.
- Añade la subcarpeta `Basis` que hay dentro como proyecto existente en Unity Hub, tal como se describe en [Abrir el proyecto en Unity Hub](#opening-the-project-in-unity-hub).

![Descargar ZIP desde GitHub](/img/getting-started/3.png)

### Abrir el proyecto en Unity Hub [#opening-the-project-in-unity-hub]

La carpeta que clonaste o descomprimiste es el repositorio completo de Basis, no el proyecto de Unity. El proyecto de Unity es la subcarpeta `Basis` que hay dentro, junto a las carpetas del servidor y de las herramientas:

```text
Basis-developer/         la carpeta que descomprimiste (un clon de Git se llama simplemente Basis)
├── Basis/               el proyecto de Unity: esta es la carpeta que debes añadir en Unity Hub
│   ├── Assets/
│   ├── Packages/
│   └── ProjectSettings/
├── Basis Server/
├── tools/
└── ...
```

- En Unity Hub abre la pestaña **Projects**, haz clic en **Add** (**Open** en versiones antiguas de Hub) y elige **Add project from disk**.
- Entra en la carpeta que descomprimiste o clonaste, selecciona la carpeta interior `Basis` y confirma.
- El proyecto aparece ahora en la lista de Unity Hub. Haz clic en él para abrirlo.

<Callout type="warn">
La carpeta correcta es la que contiene `Assets`, `Packages` y `ProjectSettings`. Si en su lugar eliges la carpeta de nivel superior (por ejemplo `Basis-developer`), Unity Hub no la reconocerá como un proyecto de Unity.
</Callout>
