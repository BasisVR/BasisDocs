## Unity installeren

- Hub - https://unity.com/download
- Standalone - https://unity.com/releases/editor/archive

### Compatibele Unity-versies

Afhankelijk van de gebruikte branch, let op de versie van de Unity Editor waarop het framework is gebouwd:

✓ [Developer](https://github.com/BasisVR/Basis/blob/developer/Basis/ProjectSettings/ProjectVersion.txt#L1)  
✓ [Long-Term-Support](https://github.com/BasisVR/Basis/blob/long-term-support/Basis/ProjectSettings/ProjectVersion.txt#L1)

### Aanvullende Unity-modules

Voeg de volgende modules toe via het scherm "Modules toevoegen" bij het installeren van de Unity Editor-versie:

```ts tab="Windows"

   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (Mono) 
✓ Mac Build Support (Mono)
```

<Callout type="info">
Zelfs als je alleen gebruikersgegenereerde content maakt voor Avatar en Wereld, heb je deze aanvullende modules nog steeds nodig om deze content beschikbaar te maken op deze platformen.

Als je de juiste Unity-versie al hebt geïnstalleerd maar de optie "Modules toevoegen" niet beschikbaar is, is deze waarschijnlijk buiten Unity Hub geïnstalleerd. Installeer de juiste Unity-versie opnieuw via Unity Hub.
</Callout>

## Het Basis-framework verkrijgen

### Git

Je kunt de `developer`- of `long-term-support`-branches op https://github.com/BasisVR/Basis rechtstreeks [klonen](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) of [forken](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo) naar je eigen lokale repository. Het Unity-project is de submap `Basis` in de kloon (`Basis/Basis`), zie [Het project openen in Unity Hub](#opening-the-project-in-unity-hub) hieronder.

### Direct ZIP-download

Voor degenen die de Git-ervaring willen overslaan:

- Selecteer het vervolgkeuzemenu 'Code' rechtsboven en klik op Download ZIP.
- Pak het ZIP-bestand uit naar een map naar keuze. Het wordt uitgepakt in een map met de naam van de branch, bijvoorbeeld `Basis-developer`.
- Voeg de submap `Basis` daarin toe als een bestaand project in Unity Hub, zoals beschreven in [Het project openen in Unity Hub](#opening-the-project-in-unity-hub).

![ZIP downloaden van GitHub](/img/getting-started/3.png)

### Het project openen in Unity Hub [#opening-the-project-in-unity-hub]

De map die je hebt gekloond of uitgepakt is de volledige Basis-repository, niet het Unity-project. Het Unity-project is de submap `Basis` daarin, naast de mappen voor de server en de tools:

```text
Basis-developer/         de uitgepakte map (een Git-kloon heet gewoon Basis)
├── Basis/               het Unity-project: dit is de map die je in Unity Hub toevoegt
│   ├── Assets/
│   ├── Packages/
│   └── ProjectSettings/
├── Basis Server/
├── tools/
└── ...
```

- Open in Unity Hub het tabblad **Projects**, klik op **Add** (**Open** in oudere Hub-versies) en kies **Add project from disk**.
- Blader naar de uitgepakte of gekloonde map, selecteer de binnenste map `Basis` en bevestig.
- Het project staat nu in de lijst van Unity Hub. Klik erop om het te openen.

<Callout type="warn">
De juiste map is de map die `Assets`, `Packages` en `ProjectSettings` bevat. Kies je in plaats daarvan de bovenste map (bijvoorbeeld `Basis-developer`), dan herkent Unity Hub deze niet als een Unity-project.
</Callout>
