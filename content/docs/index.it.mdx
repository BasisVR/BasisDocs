Benvenuto nel wiki di Basis!

Questa pagina fornisce i passaggi minimi necessari per avviare un progetto Basis, incluse le guide per la creazione di bundle di asset per Avatar e Mondo.

## Requisiti di sistema attuali

https://docs.unity3d.com/Manual/system-requirements.html

## Installare Unity

- Hub - https://unity.com/download
- Standalone - https://unity.com/releases/editor/archive

### Versioni di Unity compatibili

A seconda del branch utilizzato, osserva la versione dell'Unity Editor su cui è costruito il framework:

✓ [Developer](https://github.com/BasisVR/Basis/blob/developer/Basis/ProjectSettings/ProjectVersion.txt#L1)  
✓ [Long-Term-Support](https://github.com/BasisVR/Basis/blob/long-term-support/Basis/ProjectSettings/ProjectVersion.txt#L1)

### Moduli Unity aggiuntivi

Aggiungi i seguenti moduli tramite la schermata "Aggiungi moduli" durante l'installazione della versione dell'Unity Editor:

```ts tab="Windows"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (Mono) 
✓ Mac Build Support (Mono)
✓ Windows Build Support (IL2CPP)
```

```ts tab="Mac"

   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (Mono)
✓ Mac Build Support (IL2CPP)
```

```ts tab="Linux"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (IL2CPP)
✓ Mac Build Support (Mono)

```

<Callout type="info">
Anche se stai costruendo solo contenuti generati dagli utenti per la creazione di Avatar e Mondi, avrai comunque bisogno di questi moduli aggiuntivi per rendere questi contenuti disponibili su queste piattaforme.
</Callout>

<Callout type="info">
Se hai già installata la versione corretta di Unity ma l'opzione "Aggiungi moduli" non è disponibile, probabilmente è stata installata esternamente da Unity Hub. Reinstalla la versione corretta di Unity da Unity Hub.
</Callout>

## Acquisire il framework Basis

### Git

Puoi direttamente [clonare](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) i branch `developer` o `long-term-support` disponibili su https://github.com/BasisVR/Basis oppure [fare un fork](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo) nel tuo repository locale. Il progetto Unity è la sottocartella `Basis` all'interno del clone (`Basis/Basis`), vedi [Aprire il progetto in Unity Hub](#opening-the-project-in-unity-hub) più avanti.

### Download ZIP diretto

Per chi preferisce non usare Git:

- Seleziona il menu a tendina 'Code' in alto a destra e poi Scarica ZIP.
- Estrai lo ZIP in qualsiasi cartella o destinazione desideri. Viene estratto in una cartella con il nome del branch, ad esempio `Basis-developer`.
- Aggiungi la sottocartella `Basis` al suo interno come progetto esistente in Unity Hub, come descritto in [Aprire il progetto in Unity Hub](#opening-the-project-in-unity-hub).

![Scarica ZIP da GitHub](/img/getting-started/3.png)

### Aprire il progetto in Unity Hub [#opening-the-project-in-unity-hub]

La cartella che hai clonato o estratto è l'intero repository Basis, non il progetto Unity. Il progetto Unity è la sottocartella `Basis` al suo interno, accanto alle cartelle del server e degli strumenti:

```text
Basis-developer/         la cartella estratta (un clone Git si chiama semplicemente Basis)
├── Basis/               il progetto Unity: questa è la cartella da aggiungere in Unity Hub
│   ├── Assets/
│   ├── Packages/
│   └── ProjectSettings/
├── Basis Server/
├── tools/
└── ...
```

- In Unity Hub apri la scheda **Projects**, fai clic su **Add** (**Open** nelle versioni precedenti di Hub) e scegli **Add project from disk**.
- Entra nella cartella estratta o clonata, seleziona la cartella interna `Basis` e conferma.
- Il progetto compare ora nell'elenco di Unity Hub. Fai clic su di esso per aprirlo.

<Callout type="warn">
La cartella corretta è quella che contiene `Assets`, `Packages` e `ProjectSettings`. Se invece scegli la cartella di primo livello (ad esempio `Basis-developer`), Unity Hub non la riconoscerà come progetto Unity.
</Callout>
