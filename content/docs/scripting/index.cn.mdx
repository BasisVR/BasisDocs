## 概述

脚本在 Basis 框架内提供高级功能。本文档将引导您使用 Unity 和 Basis SDK 创建、构建和测试脚本。

## Native 与 Cilbox

Basis 有两种脚本：

- **Native** 脚本编译进应用程序。它们拥有完整的 Unity 和 Basis API 以及原生速度，但只存在于包含它们的客户端构建中。在 Basis 上构建应用程序或游戏时使用它们。
- **Cilbox** 脚本是运行时脚本。它们随世界、道具或虚拟形象一起发布，标记为 `[Cilboxable]`，并在任何加载该内容的客户端上于沙盒中运行。用于用户内容。

完整的对比请参见 [Native 与 Cilbox](/cn/docs/scripting/native-and-cilbox)。
