title: Shim-Referenz
description: Alle Basis-Shims, die ein Cilbox-Skript verwenden kann, nach Bereich gruppiert und jeweils mit einem kurzen Beispiel.
---

Shims sind die Basis-Seite der Cilbox-Sandbox: kleine, sichere APIs, die einem Sandbox-Skript Zugriff auf Spieler, Eingabe, Networking, Speichern, Menüs und mehr geben. Die meisten befinden sich im Namespace `Basis.Shims`.

Shims gibt es in drei Formen:

- Statische Klassen, die Sie direkt aufrufen, zum Beispiel `BasisPlayersShim.Count`.
- Event-Komponenten, für die Sie sich anmelden, indem Sie in `Start` `GetComponent<T>()` aufrufen. Cilbox fügt die Komponente für Sie hinzu, und Basis ruft auf Ihrem Skript eine Methode mit einem festgelegten Namen auf, zum Beispiel `OnPlatformChanged`.
- Ersetzte Typen. Sie schreiben den normalen Unity-Namen (`Debug`, `VideoPlayer`, `BasisAvatar`), und die Sandbox stellt eine sichere Version bereit.
