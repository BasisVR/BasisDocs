При загрузке контента **content police** Basis удаляет каждый компонент, тип которого не входит в список разрешённых для данного типа контента. Скрипты с атрибутом `[Cilboxable]` сохраняются, потому что сначала преобразуются в прокси в песочнице.

## Списки разрешённых

Списки находятся в `Packages/com.basis.sdk/Settings/`:

| Ассет | Применяется к |
| --- | --- |
| `SceneContentPoliceSelector` | Мирам |
| `PropContentPoliceSelector` | Пропам |
| `AvatarContentPoliceSelector` | Аватарам |

Каждый из них представляет собой список полных имён типов. Сопоставление точное: подкласс разрешённого типа **не** разрешён, если он сам не указан в списке.

## Что разрешено по умолчанию

**Миры и пропы:** рендеринг (компоненты mesh, skinned mesh, line, trail, частиц и LOD, источники света, reflection probes, камеры), физика (коллайдеры, rigidbody, joints), источники звука и Steam Audio, аниматоры и анимация, UI canvas и TextMesh Pro, `VideoPlayer`, биндеры VFX Graph, AudioLink, констрейнты Basis, медиаплеер Basis, зеркало, сиденья, предметы для подбора, `BasisSyncedTransform`, `BasisPickupSyncNetworking`, `BasisSeatSync`, транспорт, `BasisPlatformSwitch`, а также песочница Cilbox и шимы. И там, и там разрешена навигация (`NavMeshAgent`, `NavMeshObstacle`). В мирах также разрешены тома постобработки и пьедестал аватара. Список для пропов не включает `BasisNetworkShim`. В пропе добавляйте его из кода через `SafeUtil.MakeNetworkable(this)`.

**Аватары:** рендеринг, физика, звук, аниматоры, констрейнты, сиденья, синхронизированные трансформы, OSC, шимы аватаров, зеркала, предметы для подбора, VFX Graph и видео через медиаплеер Basis, FFUnity и плеер ytdlp из AudioLink. Без камер, источников света, UI и `VideoPlayer`.

**Не разрешено по умолчанию** (только в сборках клиента): `BasisSyncedParameters`, `BasisSyncedRigidbody`, `BasisLocomotionZone`, `BasisRuntimeLoader` и любые ваши собственные нативные `MonoBehaviour`.

<Callout type="info">
Ассеты селекторов являются источником истины и меняются между версиями. Откройте их в инспекторе, чтобы увидеть актуальный список.
</Callout>

## Проверка контента

- Раздел **Content Police** в инспекторах Basis Avatar, Prop и Scene показывает, что будет удалено. Контент проверяется только при загрузке в клиенте, а не во время сборки. Проверьте здесь перед загрузкой на сервер.
- Когда клиент удаляет компонент, он пишет в лог `Component X is not approved and will be removed`.
- Окно **Basis > Tools > Cilbox Permissions** показывает, что каждая песочница позволяет вызывать скриптам.

## Добавление компонента (сборки клиента)

Если вы выпускаете собственный клиент, добавьте полное имя типа в соответствующий ассет селектора. Контент, собранный для публичного клиента, не может на это полагаться; в этом случае перенесите логику в скрипт `[Cilboxable]`.
