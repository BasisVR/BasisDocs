## Overview

Scripting provides advanced functionality within the Basis framework. This documentation will guide you through creating, building and testing scripts using Unity and the Basis SDK.

## Native and Cilbox

Basis has two kinds of scripts:

- **Native** scripts are compiled into the application. They have the full Unity and Basis API and native speed, but only exist in clients built with them. Use them when building an app or game on Basis.
- **Cilbox** scripts are runtime scripts. They ship inside a world, prop or avatar, are marked `[Cilboxable]`, and run in a sandbox on any client that loads the content. Use them for user content.

See [Native and Cilbox](/en/docs/scripting/native-and-cilbox) for the full comparison.
