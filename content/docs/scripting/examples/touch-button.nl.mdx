---
title: Aanraakknop
description: Een knop die wordt ingedrukt door hem met een van beide handen aan te raken, met behulp van de handbotposities van de lokale speler.
---

Aanwijzen werkt overal, maar in VR voelt het beter om een knop met je vinger in te drukken. Dit leest de handposities van de lokale speler en gaat af wanneer er een dichtbij komt.

```csharp title="TouchButton.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Basis.Shims;
using Cilbox;
using UnityEngine;
using UnityEngine.Events;

[Cilboxable]
public class TouchButton : MonoBehaviour
{
    public float radius = 0.06f;
    public float cooldown = 0.5f;
    public AudioSource click;
    public GameObject target;

    bool touching;
    float nextPress;

    void Update()
    {
        IBasisPlayer local = BasisPlayersShim.Local;
        if (local == null) return;
        Vector3 center = transform.position;
        float left = (local.GetBonePosition(HumanBodyBones.LeftIndexDistal) - center).sqrMagnitude;
        float right = (local.GetBonePosition(HumanBodyBones.RightIndexDistal) - center).sqrMagnitude;
        bool now = Mathf.Min(left, right) < radius * radius;
        if (now && !touching && Time.time >= nextPress)
        {
            nextPress = Time.time + cooldown;
            Press();
        }
        touching = now;
    }

    void Press()
    {
        click.Play();
        target.SetActive(!target.activeSelf);
        BasisHapticsShim.Play(this, BasisHapticHand.Both, 0.5f, 0.05f);
    }
}
```

- Vingertopbotten vereisen een avatar met vingerbotten. Gebruik `LeftHand` en `RightHand` met een grotere straal om met de handpalm te drukken.
- `touching` zorgt ervoor dat het één keer per aanraking afgaat in plaats van elk frame.
- Om het resultaat te delen, verstuur je het als een [netwerkevent](/nl/docs/scripting/examples/synced-toggle) vanuit `Press`.
