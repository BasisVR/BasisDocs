---
title: Examples
description: Complete, copyable scripts for common world and prop features, from a spinning cube to a networked scoreboard.
---

Each example is a whole script with the scene setup it needs. They build on each other: start with **Basics** if you are new to Basis scripting, then **Synced Toggle** for your first networked script.

| Example | Shows |
| --- | --- |
| [Basics](/en/docs/scripting/examples/basics) | A Cilbox script, inspector fields, `Update`, a UI button. |
| [Synced Toggle](/en/docs/scripting/examples/synced-toggle) | A button that turns something on or off for everyone, including late joiners. |
| [Scoreboard](/en/docs/scripting/examples/scoreboard) | A synced score kept by one owner, with other players asking the owner to add points. |
| [Pickup Gun](/en/docs/scripting/examples/pickup-gun) | A synced pickup that fires, with the shot shown to everyone. |
| [Touch Button](/en/docs/scripting/examples/touch-button) | Pressing a button with your finger in VR. |
| [Seats](/en/docs/scripting/examples/seats) | Seating, turning and ejecting players from a script. |
| [Zones and Teleporters](/en/docs/scripting/examples/zones-and-teleporters) | Detecting the local player in an area, teleporting, trampolines and lobby counts. |
| [NPC Follow](/en/docs/scripting/examples/npc-follow) | A NavMesh agent simulated by one owner and sent to everyone. |
| [Image Loading](/en/docs/scripting/examples/image-loading) | Showing a picture from a URL on a sign. |
| [Minimap](/en/docs/scripting/examples/minimap) | A top down camera following the local player onto a render texture. |
| [Persistence](/en/docs/scripting/examples/persistence) | Saving and loading a player's progress. |
| [Settings Tab](/en/docs/scripting/examples/settings-tab) | Adding world options to the player's menu. |

All examples are also in the Unity editor under **Basis > Creator Guide**, where each code block has a copy button.
