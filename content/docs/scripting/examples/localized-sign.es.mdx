---
title: Cartel localizado
description: Un cartel que muestra texto en el idioma del jugador y cambia en directo cuando este lo cambia, usando BasisLanguageEventShim.
---

```csharp title="LocalizedSign.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class LocalizedSign : MonoBehaviour
{
    public TextMeshPro label;
    public string[] languageCodes = { "en", "de", "fr", "ja" };
    public string[] texts = { "Welcome", "Willkommen", "Bienvenue", "ようこそ" };

    void Start()
    {
        GetComponent<BasisLanguageEventShim>();
    }

    void OnLanguageChanged(string code)
    {
        label.text = texts[0];
        for (int i = 0; i < languageCodes.Length; i++)
        {
            if (code.StartsWith(languageCodes[i])) { label.text = texts[i]; return; }
        }
    }
}
```

- `OnLanguageChanged` se llama una vez de inmediato con el idioma actual.
- Comparar con `StartsWith` permite que `es` cubra también `es-MX`.
- Establezca los arrays en el inspector en lugar de con un inicializador si su sandbox rechaza los inicializadores de arrays, y asegúrese de que la fuente tenga los glifos que necesita.
