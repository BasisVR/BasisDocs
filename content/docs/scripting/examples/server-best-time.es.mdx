---
title: Mejor tiempo en el servidor
description: Guardar la mejor vuelta de cada jugador en el servidor con BasisServerStorageShim, donde le sigue entre dispositivos.
---

import { Callout } from 'fumadocs-ui/components/callout';

`BasisSaveShim` guarda en el equipo del jugador. `BasisServerStorageShim` guarda en el **servidor**, por jugador. Un mejor tiempo conseguido en PC sigue ahí cuando el jugador visita desde Quest.

```csharp title="ServerBestTime.cs (Cilbox)"
using System.Globalization;
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class ServerBestTime : MonoBehaviour
{
    const string Key = "best-lap";
    public TextMeshPro label;
    float best = float.MaxValue;

    void Start()
    {
        if (!BasisServerStorageShim.IsAvailable(this)) { label.text = "Times are not saved on this server"; return; }
        BasisServerStorageShim.LoadString(this, Key, (result, text) =>
        {
            if (result == BasisServerStorageResult.Ok && float.TryParse(text, NumberStyles.Float, CultureInfo.InvariantCulture, out float saved)) best = saved;
            Show();
        });
    }

    public void LapFinished(float seconds)
    {
        if (seconds >= best) return;
        best = seconds;
        Show();
        BasisServerStorageShim.SaveString(this, Key, best.ToString("F3", CultureInfo.InvariantCulture), result =>
        {
            if (result != BasisServerStorageResult.Ok) Debug.LogWarning($"best lap not saved: {result}");
        });
    }

    void Show() => label.text = best < float.MaxValue ? $"Your best: {best:F2}s" : "No lap yet";
}
```

El tiempo se escribe y se lee con `CultureInfo.InvariantCulture`, de modo que un mejor tiempo guardado en un PC configurado en alemán (`12,345`) se lee correctamente en un Quest configurado en inglés.

<Callout type="info">
El almacenamiento es por jugador y por servidor, con un total pequeño (16 KB por defecto) compartido por todo el contenido. Guarde valores compactos, no registros.
</Callout>
