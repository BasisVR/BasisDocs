---
title: Boids
description: Ein Schwarm aus 200 Vögeln, der in Cilbox günstig animiert wird, indem Transform-Schreibvorgänge mit BasisTransformBatchShim gebündelt werden.
---

200 Transforms einzeln aus einem Cilbox-Skript zu bewegen kostet Hunderte interpretierte Aufrufe pro Frame. Mit Batching wird daraus ein einziger.

```csharp title="Flock.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Flock : MonoBehaviour
{
    public Transform[] birds;
    public float radius = 10f;
    public float speed = 0.4f;

    float[] xyz;
    float[] phase;

    void Start()
    {
        xyz = new float[birds.Length * 3];
        phase = new float[birds.Length];
        for (int i = 0; i < phase.Length; i++) phase[i] = i * 0.37f;
    }

    void Update()
    {
        float t = Time.time * speed;
        Vector3 c = transform.position;
        float cx = c.x, cy = c.y, cz = c.z;
        for (int i = 0; i < birds.Length; i++)
        {
            float a = t + phase[i];
            xyz[i * 3] = cx + Mathf.Cos(a) * radius;
            xyz[i * 3 + 1] = cy + Mathf.Sin(a * 2f) * 2f;
            xyz[i * 3 + 2] = cz + Mathf.Sin(a) * radius;
        }
        BasisTransformBatchShim.SetPositions(birds, xyz);
    }
}
```

- Die Mathematik läuft auf einfachen floats, was im Interpreter viel günstiger ist als `Vector3`-Operatoren.
- `SetPositions(Transform[], float[])` schreibt jeden Vogel in einem einzigen nativen Aufruf.
- Verwenden Sie `BasisNetworkTimeShim.ServerTimeSeconds` statt `Time.time`, wenn der Schwarm zwischen Spielern exakt übereinstimmen muss.
