---
title: Linterna de mano
description: Una linterna fijada a la mano del jugador local sin retraso, usando BasisBeforeRenderShim y la entrada de los mandos.
---

```csharp title="HandFlashlight.cs (Cilbox, world)"
using Basis.Scripts.BasisSdk.Players;
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class HandFlashlight : MonoBehaviour
{
    public Light beam;

    void Start()
    {
        GetComponent<BasisBeforeRenderShim>();
    }

    void Update()
    {
        if (BasisControllerInputShim.GetButtonDown(BasisControllerHand.Right, BasisControllerButton.Secondary))
            beam.enabled = !beam.enabled;
    }

    void OnBeforeRender()
    {
        IBasisPlayer me = BasisPlayersShim.Local;
        if (me == null) return;
        transform.SetPositionAndRotation(me.GetBonePosition(HumanBodyBones.RightHand), me.GetBoneRotation(HumanBodyBones.RightHand));
    }
}
```

- Escribir la posición en `Update` haría que la linterna fuera un fotograma por detrás de la mano en VR, porque el IK termina más tarde. `OnBeforeRender` se ejecuta después del IK.
- La luz es local: cada jugador tiene la suya y los demás no la ven.
