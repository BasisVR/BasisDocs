---
title: サンプル
description: ワールドやプロップのよくある機能を実装した、コピーして使える完全なスクリプト。回転するキューブからネットワーク対応のスコアボードまで。
---

各サンプルは、必要なシーンのセットアップを含む完全なスクリプトです。サンプルは互いに積み重なっています。Basisのスクリプティングが初めてなら**基本**から始め、次に最初のネットワーク対応スクリプトとして**同期トグル**に進んでください。

| サンプル | 内容 |
| --- | --- |
| [基本](/ja/docs/scripting/examples/basics) | Cilboxスクリプト、インスペクターのフィールド、`Update`、UIボタン。 |
| [同期トグル](/ja/docs/scripting/examples/synced-toggle) | 途中参加者を含む全員に対して何かをオン・オフするボタン。 |
| [スコアボード](/ja/docs/scripting/examples/scoreboard) | 1人のオーナーが管理する同期スコア。他のプレイヤーはオーナーにポイントの追加を依頼します。 |
| [ピックアップ銃](/ja/docs/scripting/examples/pickup-gun) | 発射できる同期ピックアップ。発射は全員に表示されます。 |
| [タッチボタン](/ja/docs/scripting/examples/touch-button) | VRで指を使ってボタンを押す。 |
| [座席](/ja/docs/scripting/examples/seats) | スクリプトからプレイヤーを座らせる、向きを変える、降ろす。 |
| [ゾーンとテレポーター](/ja/docs/scripting/examples/zones-and-teleporters) | エリア内のローカルプレイヤーの検出、テレポート、トランポリン、ロビーの人数。 |
| [NPCの追従](/ja/docs/scripting/examples/npc-follow) | 1人のオーナーがシミュレーションし、全員に送信されるNavMeshエージェント。 |
| [画像の読み込み](/ja/docs/scripting/examples/image-loading) | URLから取得した画像を看板に表示する。 |
| [ミニマップ](/ja/docs/scripting/examples/minimap) | ローカルプレイヤーを追従する見下ろしカメラをレンダーテクスチャに映す。 |
| [永続化](/ja/docs/scripting/examples/persistence) | プレイヤーの進行状況の保存と読み込み。 |
| [設定タブ](/ja/docs/scripting/examples/settings-tab) | プレイヤーのメニューにワールドのオプションを追加する。 |
| [昼夜サイクル](/ja/docs/scripting/examples/day-night-cycle) | 共有のサーバー時計に従う太陽。ネットワーク処理は不要です。 |
| [ラウンドタイマー](/ja/docs/scripting/examples/round-timer) | ラウンドごとに1通のメッセージで同期されるカウントダウン。 |
| [トリビアクイズ](/ja/docs/scripting/examples/trivia-quiz) | JSONファイルから読み込んだ問題と、同期される現在の問題。 |
| [サーバーのベストタイム](/ja/docs/scripting/examples/server-best-time) | `BasisServerStorageShim`を使ったサーバー上のプレイヤーごとの保存。 |
| [スタッフ用ドア](/ja/docs/scripting/examples/staff-door) | 管理者とモデレーター用の、ライブで更新されるドア。 |
| [ボイスステージ](/ja/docs/scripting/examples/voice-stage) | 話者の声をステージのスピーカーから流す。 |
| [お絵かきボード](/ja/docs/scripting/examples/drawing-board) | 途中参加者向けに圧縮スナップショットを送る共有ホワイトボード。 |
| [ランダムな戦利品](/ja/docs/scripting/examples/random-loot) | メッセージなしで全員に同じランダムなアイテム。 |
| [エレベーター](/ja/docs/scripting/examples/elevator) | 1つの同期された数値で動く共有の移動プラットフォーム。 |
| [しっぽの反応](/ja/docs/scripting/examples/tail-reaction) | 揺れボーンを掴まれたときに反応するアバター。 |
| [手持ちの懐中電灯](/ja/docs/scripting/examples/hand-flashlight) | 遅延なくオブジェクトを手に固定する。 |
| [デスクトップとVRの入力](/ja/docs/scripting/examples/desktop-and-vr-input) | マウスクリックとVRのトリガーを1つのスクリプトで扱う。 |
| [ローカライズされた看板](/ja/docs/scripting/examples/localized-sign) | プレイヤーの言語で表示されるテキスト。 |
| [パフォーマンススケーラー](/ja/docs/scripting/examples/performance-scaler) | フレームレートが下がったときにエフェクトを削減する。 |
| [サーバーポータル](/ja/docs/scripting/examples/server-portal) | プレイヤーを別のサーバーに送る。 |
| [Boids](/ja/docs/scripting/examples/boids) | 1フレームに1回のまとめた呼び出しでアニメーションする200羽の鳥。 |

すべてのサンプルはUnityエディターの**Basis > Creator Guide**にも収録されており、各コードブロックにはコピーボタンがあります。
