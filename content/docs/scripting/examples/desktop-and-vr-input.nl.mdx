---
title: Desktop- en VR-invoer
description: Eén script dat een blaster afvuurt met een VR-trigger of een muisklik, met haptische feedback in VR.
---

```csharp title="Blaster.cs (Cilbox, world)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Blaster : MonoBehaviour
{
    public Transform muzzle;
    public AudioSource shot;
    public float cooldown = 0.25f;
    float next;

    void Update()
    {
        bool fire = false;
        if (BasisPlatformShim.IsVR)
        {
            fire = BasisControllerInputShim.GetButtonDown(BasisControllerHand.Right, BasisControllerButton.Trigger);
        }
        else if (BasisDesktopInputShim.HasMouse)
        {
            fire = BasisDesktopInputShim.GetMouseButtonDown(0);
        }
        if (!fire || Time.time < next) return;
        next = Time.time + cooldown;
        shot.Play();
        if (BasisPlatformShim.IsVR) BasisHapticsShim.Play(this, BasisHapticHand.Right, 0.7f, 0.06f);
        if (Physics.Raycast(muzzle.position, muzzle.forward, out RaycastHit hit, 50f)) Debug.Log(hit.collider.name);
    }
}
```

- Gebruik voor een vastgehouden voorwerp liever **Basis Pickup Interactable** en `OnPickupUse` ([Pickup-geweer](/nl/docs/scripting/examples/pickup-gun)), wat op elk platform hetzelfde werkt.
- Controllerinvoer leest als losgelaten zolang het menu open is. Wie op menuknoppen klikt, vuurt de blaster niet af.
