## Zona del giocatore locale

Controllare periodicamente la posizione del giocatore locale rispetto ai bounds di un trigger funziona allo stesso modo negli script nativi e Cilbox, e non dipende dai layer della fisica.

```csharp title="LocalPlayerZone.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class LocalPlayerZone : MonoBehaviour
{
    public Collider area;
    public GameObject showWhileInside;
    bool inside;

    void Start()
    {
        showWhileInside.SetActive(false);
    }

    void Update()
    {
        BasisLocalPlayer local = BasisLocalPlayer.Instance;
        if (local == null) return;
        local.GetPositionAndRotation(out Vector3 position, out Quaternion rotation);
        bool now = area.bounds.Contains(position);
        if (now == inside) return;
        inside = now;
        showWhileInside.SetActive(inside);
    }
}
```

<Callout type="info">
Per modificare il movimento all'interno di un'area (bassa gravità, volo, camminata più veloce), usa gli override di locomozione su `BasisLocalPlayer` descritti in [Usi comuni](/it/docs/scripting/common-usages). Nelle build del client, il componente **Basis Locomotion Zone** fa lo stesso senza codice.
</Callout>

## Teletrasporto

Aggiungilo a una pedana o a un pulsante. Il teletrasporto influisce solo sul giocatore locale. Ogni giocatore teletrasporta se stesso e nulla passa per la rete.

```csharp title="Teleporter.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Teleporter : MonoBehaviour
{
    public Collider pad;
    public Transform destination;
    bool wasOnPad;

    void Update()
    {
        BasisLocalPlayer local = BasisLocalPlayer.Instance;
        if (local == null) return;
        local.GetPositionAndRotation(out Vector3 position, out Quaternion rotation);
        bool onPad = pad.bounds.Contains(position);
        if (onPad && !wasOnPad) TeleportNow();
        wasOnPad = onPad;
    }

    public void TeleportNow()
    {
        BasisLocalPlayer.Instance.Teleport(destination.position, destination.rotation, BasisTeleportMode.Instant);
    }
}
```

## Trampolino

`BasisVelocityShim` è disponibile nei mondi. Mantieni la velocità orizzontale e sostituisci la caduta con un rimbalzo.

```csharp title="Trampoline.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Trampoline : MonoBehaviour
{
    public Collider surface;
    public float bounce = 9f;

    void Update()
    {
        BasisLocalPlayer local = BasisLocalPlayer.Instance;
        if (local == null) return;
        local.GetPositionAndRotation(out Vector3 position, out Quaternion rotation);
        if (!surface.bounds.Contains(position)) return;
        Vector3 velocity = BasisVelocityShim.Velocity;
        if (velocity.y > 0.5f) return;
        BasisVelocityShim.SetVelocity(new Vector3(velocity.x, bounce, velocity.z));
    }
}
```

## Conteggio della lobby

Mostra quanti giocatori si trovano in un'area della lobby. Ogni client conta per conto proprio a partire dalle posizioni dei giocatori e non vengono inviati messaggi.

```csharp title="LobbyCounter.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class LobbyCounter : MonoBehaviour
{
    public Transform center;
    public float radius = 4f;
    public int needed = 4;
    public TextMeshPro label;
    float nextCheck;

    void Update()
    {
        if (Time.time < nextCheck) return;
        nextCheck = Time.time + 0.5f;
        int count = 0;
        foreach (IBasisPlayer player in BasisPlayersShim.Within(center.position, radius)) count++;
        label.text = count >= needed ? "Ready!" : $"{count} / {needed} players";
    }
}
```

Controllare due volte al secondo invece che a ogni frame è più che sufficiente per un cartello.
