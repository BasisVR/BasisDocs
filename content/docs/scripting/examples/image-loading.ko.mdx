## 설정

1. 표지판용 **Quad**를 만들고 unlit 또는 lit 텍스처 슬롯이 있는 머티리얼을 지정합니다.
2. **RemoteImage**를 추가하고 렌더러를 할당합니다. URL과 선택적인 플레이스홀더 텍스처를 설정합니다.

## 스크립트

```csharp title="RemoteImage.cs (Cilbox)"
using Basis;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class RemoteImage : MonoBehaviour
{
    public string url = "https://example.com/poster.png";
    public Renderer target;
    public Texture placeholder;
    public float refreshMinutes = 0f;

    float nextRefresh;

    void Start()
    {
        if (placeholder != null) target.material.mainTexture = placeholder;
        Load();
    }

    void Update()
    {
        if (refreshMinutes <= 0f || Time.time < nextRefresh) return;
        Load();
    }

    void Load()
    {
        nextRefresh = Time.time + refreshMinutes * 60f;
        var downloader = new BasisImageDownloader();
        downloader.DownloadImage(url, result =>
        {
            if (result.Success) target.material.mainTexture = result.Result;
            else Debug.LogWarning($"poster failed: {result.Error}");
        });
    }
}
```

## 규칙

- https 전용. 일반 http, IP 주소 직접 사용, 로컬 네트워크 주소로 해석되는 모든 것은 요청을 보내기 전에 거부됩니다.
- 리디렉션 없음. 이미지를 최종 주소에 호스팅하세요.
- 플레이어가 호스트를 승인합니다. 콘텐츠가 처음으로 새 호스트를 요청하면 플레이어에게 확인 창이 뜹니다. 수락하기 전까지 다운로드는 실패하고 플레이스홀더가 유지됩니다.
- 모든 플레이어가 각자 이미지를 다운로드합니다. 동기화할 것은 없습니다. 모든 사람이 같은 바뀌는 이미지를 보게 하려면 **URL 인덱스**를 동기화하고(패턴은 [동기화 토글](/ko/docs/scripting/examples/synced-toggle) 참조) 로컬에서 로드하세요.

<Callout type="info">
텍스트에는 같은 규칙으로 `BasisStringDownloader.DownloadString`을 사용하고, JSON을 읽으려면 `BasisJson.Parse`를 사용하세요.
</Callout>
