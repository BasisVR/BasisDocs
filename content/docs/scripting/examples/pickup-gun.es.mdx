## Configuración

1. Modele o importe una pistola. Añada un collider y un **Rigidbody**.
2. Añada **Basis Pickup Interactable**.
3. Añada **Basis Pickup Sync Networking** y asigne el pickup. Esto sincroniza la posición de la pistola y quién la sostiene.
4. Añada un **AudioSource** y un **ParticleSystem** para el fogonazo, y un transform hijo en la boca del cañón.
5. Añada **PickupGun** y asigne todo.

## Script

```csharp title="PickupGun.cs (Cilbox)"
using Basis;
using Basis.Network.Core;
using Basis.Scripts.BasisSdk.Interactions;
using Basis.Scripts.Device_Management.Devices;
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class PickupGun : MonoBehaviour
{
    public BasisPickupInteractable pickup;
    public Transform muzzle;
    public AudioSource shotSound;
    public ParticleSystem flash;
    public float range = 50f;
    public float cooldown = 0.2f;

    BasisNetworkShim net;
    bool held;
    float nextShot;

    void Start()
    {
        net = GetComponent<BasisNetworkShim>();
        net.NetworkMessageReceived += OnMessage;
        pickup.OnInteractStartEvent.AddListener(OnGrab);
        pickup.OnInteractEndEvent.AddListener(OnDrop);
        pickup.OnPickupUse.AddListener(OnUse);
    }

    void OnDestroy()
    {
        if (net != null) net.NetworkMessageReceived -= OnMessage;
    }

    void OnGrab(BasisInput input) { held = true; }
    void OnDrop(BasisInput input) { held = false; }

    void OnUse(BasisPickUpUseMode mode)
    {
        if (!held || mode != BasisPickUpUseMode.OnPickUpUseDown || Time.time < nextShot) return;
        nextShot = Time.time + cooldown;

        PlayShot();
        BasisHapticsShim.Play(this, BasisHapticHand.Both, 0.6f, 0.08f);
        if (net.HasNetworkID) net.SendCustomNetworkEvent(new byte[] { 1 }, DeliveryMethod.ReliableUnordered);

        if (Physics.Raycast(muzzle.position, muzzle.forward, out RaycastHit hit, range))
        {
            Debug.Log($"hit {hit.collider.name}");
        }
    }

    void OnMessage(ushort sender, byte[] buffer, DeliveryMethod method)
    {
        if (buffer != null && buffer.Length == 1 && buffer[0] == 1) PlayShot();
    }

    void PlayShot()
    {
        shotSound.Play();
        flash.Play();
    }
}
```

## Cómo funciona

- **Basis Pickup Sync Networking** toma la propiedad cuando se agarra la pistola y transmite su pose. Todos la ven en la mano de quien la sostiene sin ningún código.
- El disparo es un evento, no un estado. Nadie que se una más tarde necesita saber que hubo un disparo, y no hay código para jugadores que se unen tarde.
- Solo el tirador lanza el raycast. Los resultados de impacto que importan para la jugabilidad (daño, puntuación) deben decidirse en el tirador y enviarse como un evento propio, o dirigirse a un propietario como en el [Marcador](/es/docs/scripting/examples/scoreboard).

<Callout type="info">
Desactive **CanNetworkSteal** en el componente de sincronización si los demás jugadores no deben poder quitarle la pistola de la mano a alguien.
</Callout>
