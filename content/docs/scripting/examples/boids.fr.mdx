---
title: Boids
description: Une nuée de 200 oiseaux animée à moindre coût dans Cilbox en regroupant les écritures de transforms avec BasisTransformBatchShim.
---

Déplacer 200 transforms un par un depuis un script Cilbox coûte des centaines d'appels interprétés par image. Le traitement par lots les réduit à un seul.

```csharp title="Flock.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Flock : MonoBehaviour
{
    public Transform[] birds;
    public float radius = 10f;
    public float speed = 0.4f;

    float[] xyz;
    float[] phase;

    void Start()
    {
        xyz = new float[birds.Length * 3];
        phase = new float[birds.Length];
        for (int i = 0; i < phase.Length; i++) phase[i] = i * 0.37f;
    }

    void Update()
    {
        float t = Time.time * speed;
        Vector3 c = transform.position;
        float cx = c.x, cy = c.y, cz = c.z;
        for (int i = 0; i < birds.Length; i++)
        {
            float a = t + phase[i];
            xyz[i * 3] = cx + Mathf.Cos(a) * radius;
            xyz[i * 3 + 1] = cy + Mathf.Sin(a * 2f) * 2f;
            xyz[i * 3 + 2] = cz + Mathf.Sin(a) * radius;
        }
        BasisTransformBatchShim.SetPositions(birds, xyz);
    }
}
```

- Les calculs portent sur de simples floats, ce qui coûte beaucoup moins cher dans l'interpréteur que les opérateurs de `Vector3`.
- `SetPositions(Transform[], float[])` écrit tous les oiseaux en un seul appel natif.
- Utilisez `BasisNetworkTimeShim.ServerTimeSeconds` au lieu de `Time.time` si la nuée doit être parfaitement alignée entre les joueurs.
