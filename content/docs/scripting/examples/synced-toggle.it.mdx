Questo è il più piccolo script di rete completo: un byte di stato, inviato quando cambia e reinviato a chiunque entri.

## Configurazione

1. Crea un canvas in world space con un **Button**.
2. Aggiungi **SyncedToggle** al canvas. Assegna il pulsante e l'oggetto da attivare e disattivare (una luce, uno specchio, una porta).

## Script

```csharp title="SyncedToggle.cs (Cilbox)"
using Basis;
using Basis.Network.Core;
using Basis.Scripts.Networking.NetworkedAvatar;
using Cilbox;
using UnityEngine;
using UnityEngine.UI;

[Cilboxable]
public class SyncedToggle : MonoBehaviour
{
    public Button button;
    public GameObject target;
    public bool startOn = true;

    BasisNetworkShim net;
    bool on;

    void Start()
    {
        on = startOn;
        Apply();
        button.onClick.AddListener(OnPressed);
        net = GetComponent<BasisNetworkShim>();
        net.NetworkMessageReceived += OnMessage;
        net.PlayerJoined += OnPlayerJoined;
    }

    void OnDestroy()
    {
        button.onClick.RemoveAllListeners();
        if (net == null) return;
        net.NetworkMessageReceived -= OnMessage;
        net.PlayerJoined -= OnPlayerJoined;
    }

    void OnPressed()
    {
        net.TakeOwnership();
        on = !on;
        Apply();
        Send(null);
    }

    void OnMessage(ushort sender, byte[] buffer, DeliveryMethod method)
    {
        if (buffer == null || buffer.Length < 1) return;
        on = buffer[0] != 0;
        Apply();
    }

    void OnPlayerJoined(BasisNetworkPlayer player)
    {
        if (net.HasNetworkID && net.IsOwnedLocallyOnServer) Send(new[] { player.playerId });
    }

    void Send(ushort[] recipients)
    {
        if (!net.HasNetworkID) return;
        net.SendCustomNetworkEvent(new[] { on ? (byte)1 : (byte)0 }, DeliveryMethod.ReliableSequenced, recipients);
    }

    void Apply()
    {
        target.SetActive(on);
    }
}
```

## Come funziona

- **Premere** prende l'ownership, inverte il valore localmente così chi preme lo vede subito, e invia il nuovo valore a tutti gli altri.
- **`ReliableSequenced`** garantisce che arrivi l'ultimo valore e scarta quelli più vecchi, il che è esattamente ciò che serve per un interruttore.
- **Un giocatore che entra** riceve il valore attuale solo dal proprietario. Poiché il messaggio contiene l'intero stato, lo stesso `OnMessage` gestisce sia le modifiche in tempo reale sia l'aggiornamento iniziale.

<Callout type="info">
Versione nativa: deriva da `BasisNetworkBehaviour`, sostituisci gli eventi dello shim con gli override `OnNetworkMessage` e `OnPlayerJoined`, e chiama direttamente `TakeOwnership()` e `SendCustomNetworkEvent`.
</Callout>
