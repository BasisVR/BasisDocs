---
title: Exemples
description: Des scripts complets et prêts à copier pour les fonctionnalités courantes de mondes et de props, d'un cube qui tourne à un tableau des scores en réseau.
---

Chaque exemple est un script entier accompagné de la configuration de scène dont il a besoin. Ils s'appuient les uns sur les autres : commencez par **Bases** si vous débutez avec les scripts Basis, puis **Interrupteur synchronisé** pour votre premier script en réseau.

| Exemple | Montre |
| --- | --- |
| [Bases](/fr/docs/scripting/examples/basics) | Un script Cilbox, des champs d'inspecteur, `Update`, un bouton d'interface. |
| [Interrupteur synchronisé](/fr/docs/scripting/examples/synced-toggle) | Un bouton qui active ou désactive quelque chose pour tout le monde, y compris les joueurs arrivés en retard. |
| [Tableau des scores](/fr/docs/scripting/examples/scoreboard) | Un score synchronisé tenu par un seul propriétaire, les autres joueurs lui demandant d'ajouter des points. |
| [Pistolet ramassable](/fr/docs/scripting/examples/pickup-gun) | Un objet ramassable synchronisé qui tire, avec le tir visible par tout le monde. |
| [Bouton tactile](/fr/docs/scripting/examples/touch-button) | Appuyer sur un bouton avec le doigt en VR. |
| [Sièges](/fr/docs/scripting/examples/seats) | Asseoir, tourner et éjecter des joueurs depuis un script. |
| [Zones et téléporteurs](/fr/docs/scripting/examples/zones-and-teleporters) | Détecter le joueur local dans une zone, téléporter, trampolines et comptage du lobby. |
| [PNJ suiveur](/fr/docs/scripting/examples/npc-follow) | Un agent NavMesh simulé par un propriétaire et envoyé à tout le monde. |
| [Chargement d'images](/fr/docs/scripting/examples/image-loading) | Afficher une image depuis une URL sur un panneau. |
| [Minicarte](/fr/docs/scripting/examples/minimap) | Une caméra vue de dessus qui suit le joueur local et rend dans une render texture. |
| [Persistance](/fr/docs/scripting/examples/persistence) | Sauvegarder et charger la progression d'un joueur. |
| [Onglet de paramètres](/fr/docs/scripting/examples/settings-tab) | Ajouter des options de monde au menu du joueur. |
| [Cycle jour/nuit](/fr/docs/scripting/examples/day-night-cycle) | Un soleil réglé sur l'horloge serveur partagée, sans aucun code réseau. |
| [Minuteur de manche](/fr/docs/scripting/examples/round-timer) | Un compte à rebours synchronisé avec un seul message par manche. |
| [Quiz](/fr/docs/scripting/examples/trivia-quiz) | Des questions tirées d'un fichier JSON, avec la question en cours synchronisée. |
| [Meilleur temps serveur](/fr/docs/scripting/examples/server-best-time) | Des sauvegardes par joueur sur le serveur avec `BasisServerStorageShim`. |
| [Porte du staff](/fr/docs/scripting/examples/staff-door) | Une porte pour les admins et les modérateurs qui se met à jour en direct. |
| [Scène vocale](/fr/docs/scripting/examples/voice-stage) | Diffuser la voix d'un orateur depuis les haut-parleurs de la scène. |
| [Tableau à dessin](/fr/docs/scripting/examples/drawing-board) | Un tableau blanc partagé avec des instantanés compressés pour les joueurs arrivés en retard. |
| [Butin aléatoire](/fr/docs/scripting/examples/random-loot) | Le même objet aléatoire pour tout le monde, sans aucun message. |
| [Ascenseur](/fr/docs/scripting/examples/elevator) | Une plateforme mobile partagée à partir d'un seul nombre synchronisé. |
| [Réaction de queue](/fr/docs/scripting/examples/tail-reaction) | Un avatar qui réagit quand on attrape ses os jiggle. |
| [Lampe torche à la main](/fr/docs/scripting/examples/hand-flashlight) | Fixer un objet à la main sans retard. |
| [Entrées bureau et VR](/fr/docs/scripting/examples/desktop-and-vr-input) | Un seul script pour les clics de souris et les gâchettes VR. |
| [Panneau localisé](/fr/docs/scripting/examples/localized-sign) | Du texte dans la langue du joueur. |
| [Ajusteur de performances](/fr/docs/scripting/examples/performance-scaler) | Réduire les effets quand la fréquence d'images chute. |
| [Portail de serveur](/fr/docs/scripting/examples/server-portal) | Envoyer des joueurs vers un autre serveur. |
| [Boids](/fr/docs/scripting/examples/boids) | 200 oiseaux animés avec un seul appel groupé par image. |

Tous les exemples se trouvent aussi dans l'éditeur Unity sous **Basis > Creator Guide**, où chaque bloc de code dispose d'un bouton de copie.
