description: Uno stormo di 200 uccelli animato a basso costo in Cilbox raggruppando in batch le scritture dei transform con BasisTransformBatchShim.
---

Muovere 200 transform uno alla volta da uno script Cilbox costa centinaia di chiamate interpretate per frame. Il batching le riduce a una.

```csharp title="Flock.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Flock : MonoBehaviour
{
    public Transform[] birds;
    public float radius = 10f;
    public float speed = 0.4f;

    float[] xyz;
    float[] phase;

    void Start()
    {
        xyz = new float[birds.Length * 3];
        phase = new float[birds.Length];
        for (int i = 0; i < phase.Length; i++) phase[i] = i * 0.37f;
    }

    void Update()
    {
        float t = Time.time * speed;
        Vector3 c = transform.position;
        float cx = c.x, cy = c.y, cz = c.z;
        for (int i = 0; i < birds.Length; i++)
        {
            float a = t + phase[i];
            xyz[i * 3] = cx + Mathf.Cos(a) * radius;
            xyz[i * 3 + 1] = cy + Mathf.Sin(a * 2f) * 2f;
            xyz[i * 3 + 2] = cz + Mathf.Sin(a) * radius;
        }
        BasisTransformBatchShim.SetPositions(birds, xyz);
    }
}
```

- I calcoli girano su float semplici, il che nell'interprete è molto più economico degli operatori di `Vector3`.
- `SetPositions(Transform[], float[])` scrive tutti gli uccelli in un'unica chiamata nativa.
- Usa `BasisNetworkTimeShim.ServerTimeSeconds` invece di `Time.time` se lo stormo deve essere esattamente allineato tra i giocatori.
