---
title: 範例
description: 常見世界與道具功能的完整、可複製腳本，從旋轉的方塊到網路同步的記分板。
---

每個範例都是一個完整的腳本，附有所需的場景設定。它們循序漸進：如果您剛接觸 Basis 腳本，請從**基礎**開始，接著用**同步切換開關**撰寫您的第一個網路腳本。

| 範例 | 展示內容 |
| --- | --- |
| [基礎](/tw/docs/scripting/examples/basics) | Cilbox 腳本、檢查器欄位、`Update`、UI 按鈕。 |
| [同步切換開關](/tw/docs/scripting/examples/synced-toggle) | 一個為所有人（包括晚加入者）開啟或關閉某樣東西的按鈕。 |
| [記分板](/tw/docs/scripting/examples/scoreboard) | 由單一擁有者保管的同步分數，其他玩家請求擁有者加分。 |
| [拾取槍](/tw/docs/scripting/examples/pickup-gun) | 可以開火的同步拾取物，射擊效果對所有人顯示。 |
| [觸控按鈕](/tw/docs/scripting/examples/touch-button) | 在 VR 中用手指按下按鈕。 |
| [座位](/tw/docs/scripting/examples/seats) | 從腳本讓玩家入座、轉向和彈出座位。 |
| [區域與傳送點](/tw/docs/scripting/examples/zones-and-teleporters) | 偵測本機玩家是否在區域內、傳送、彈跳床與大廳人數。 |
| [NPC 跟隨](/tw/docs/scripting/examples/npc-follow) | 由單一擁有者模擬並傳送給所有人的 NavMesh agent。 |
| [圖片載入](/tw/docs/scripting/examples/image-loading) | 在告示牌上顯示來自 URL 的圖片。 |
| [小地圖](/tw/docs/scripting/examples/minimap) | 跟隨本機玩家、輸出到 render texture 的俯視攝影機。 |
| [持久化](/tw/docs/scripting/examples/persistence) | 儲存與載入玩家的進度。 |
| [設定分頁](/tw/docs/scripting/examples/settings-tab) | 將世界選項加入玩家的選單。 |
| [日夜循環](/tw/docs/scripting/examples/day-night-cycle) | 依共享伺服器時鐘運行的太陽，不需要網路同步。 |
| [回合計時器](/tw/docs/scripting/examples/round-timer) | 每回合只需一則訊息的同步倒數計時。 |
| [問答遊戲](/tw/docs/scripting/examples/trivia-quiz) | 來自 JSON 檔案的題目，並同步目前的題目。 |
| [伺服器最佳時間](/tw/docs/scripting/examples/server-best-time) | 使用 `BasisServerStorageShim` 在伺服器上儲存每位玩家的資料。 |
| [員工專用門](/tw/docs/scripting/examples/staff-door) | 供管理員和版主使用、即時更新的門。 |
| [語音舞台](/tw/docs/scripting/examples/voice-stage) | 從舞台揚聲器播放講者的語音。 |
| [繪圖板](/tw/docs/scripting/examples/drawing-board) | 共享白板，並為晚加入者提供壓縮的快照。 |
| [隨機戰利品](/tw/docs/scripting/examples/random-loot) | 不需任何訊息就讓所有人得到相同的隨機物品。 |
| [電梯](/tw/docs/scripting/examples/elevator) | 由一個同步數字驅動的共享移動平台。 |
| [尾巴反應](/tw/docs/scripting/examples/tail-reaction) | 虛擬形象在其 jiggle 骨骼被抓住時做出反應。 |
| [手持手電筒](/tw/docs/scripting/examples/hand-flashlight) | 將物件無延遲地固定在手上。 |
| [桌面與 VR 輸入](/tw/docs/scripting/examples/desktop-and-vr-input) | 一個腳本同時處理滑鼠點擊與 VR 扳機。 |
| [在地化告示牌](/tw/docs/scripting/examples/localized-sign) | 以玩家的語言顯示文字。 |
| [效能調節器](/tw/docs/scripting/examples/performance-scaler) | 在影格率下降時削減效果。 |
| [伺服器傳送門](/tw/docs/scripting/examples/server-portal) | 將玩家送往另一台伺服器。 |
| [Boids](/tw/docs/scripting/examples/boids) | 每幀只用一次批次呼叫驅動 200 隻鳥的動畫。 |

所有範例也可以在 Unity 編輯器的 **Basis > Creator Guide** 中找到，每個程式碼區塊都有複製按鈕。
