---
title: Torcia in mano
description: Una torcia fissata alla mano del giocatore locale senza ritardo, usando BasisBeforeRenderShim e l'input dei controller.
---

```csharp title="HandFlashlight.cs (Cilbox, world)"
using Basis.Scripts.BasisSdk.Players;
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class HandFlashlight : MonoBehaviour
{
    public Light beam;

    void Start()
    {
        GetComponent<BasisBeforeRenderShim>();
    }

    void Update()
    {
        if (BasisControllerInputShim.GetButtonDown(BasisControllerHand.Right, BasisControllerButton.Secondary))
            beam.enabled = !beam.enabled;
    }

    void OnBeforeRender()
    {
        IBasisPlayer me = BasisPlayersShim.Local;
        if (me == null) return;
        transform.SetPositionAndRotation(me.GetBonePosition(HumanBodyBones.RightHand), me.GetBoneRotation(HumanBodyBones.RightHand));
    }
}
```

- Scrivere la posizione in `Update` farebbe restare la torcia indietro di un frame rispetto alla mano in VR, perché l'IK finisce più tardi. `OnBeforeRender` viene eseguito dopo l'IK.
- La luce è locale: ogni giocatore ha la propria e gli altri non la vedono.
