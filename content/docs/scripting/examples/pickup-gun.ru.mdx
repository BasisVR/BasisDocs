## Настройка

1. Смоделируйте или импортируйте пистолет. Добавьте collider и **Rigidbody**.
2. Добавьте **Basis Pickup Interactable**.
3. Добавьте **Basis Pickup Sync Networking** и назначьте подбираемый предмет. Это синхронизирует позицию пистолета и то, кто его держит.
4. Добавьте **AudioSource** и **ParticleSystem** для вспышки выстрела, а также дочерний трансформ у дула.
5. Добавьте **PickupGun** и назначьте всё.

## Скрипт

```csharp title="PickupGun.cs (Cilbox)"
using Basis;
using Basis.Network.Core;
using Basis.Scripts.BasisSdk.Interactions;
using Basis.Scripts.Device_Management.Devices;
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class PickupGun : MonoBehaviour
{
    public BasisPickupInteractable pickup;
    public Transform muzzle;
    public AudioSource shotSound;
    public ParticleSystem flash;
    public float range = 50f;
    public float cooldown = 0.2f;

    BasisNetworkShim net;
    bool held;
    float nextShot;

    void Start()
    {
        net = GetComponent<BasisNetworkShim>();
        net.NetworkMessageReceived += OnMessage;
        pickup.OnInteractStartEvent.AddListener(OnGrab);
        pickup.OnInteractEndEvent.AddListener(OnDrop);
        pickup.OnPickupUse.AddListener(OnUse);
    }

    void OnDestroy()
    {
        if (net != null) net.NetworkMessageReceived -= OnMessage;
    }

    void OnGrab(BasisInput input) { held = true; }
    void OnDrop(BasisInput input) { held = false; }

    void OnUse(BasisPickUpUseMode mode)
    {
        if (!held || mode != BasisPickUpUseMode.OnPickUpUseDown || Time.time < nextShot) return;
        nextShot = Time.time + cooldown;

        PlayShot();
        BasisHapticsShim.Play(this, BasisHapticHand.Both, 0.6f, 0.08f);
        if (net.HasNetworkID) net.SendCustomNetworkEvent(new byte[] { 1 }, DeliveryMethod.ReliableUnordered);

        if (Physics.Raycast(muzzle.position, muzzle.forward, out RaycastHit hit, range))
        {
            Debug.Log($"hit {hit.collider.name}");
        }
    }

    void OnMessage(ushort sender, byte[] buffer, DeliveryMethod method)
    {
        if (buffer != null && buffer.Length == 1 && buffer[0] == 1) PlayShot();
    }

    void PlayShot()
    {
        shotSound.Play();
        flash.Play();
    }
}
```

## Как это работает

- **Basis Pickup Sync Networking** берёт владение, когда пистолет захватывают, и передаёт его позу. Все видят его в руке держащего без всякого кода.
- Выстрел это событие, а не состояние. Никому из подключившихся позже не нужно знать, что был выстрел, и кода для поздно подключившихся нет.
- Луч выпускает только стреляющий. Результаты попаданий, важные для игрового процесса (урон, счёт), должен определять стреляющий и отправлять их отдельным событием, либо их нужно направлять владельцу, как в примере [Табло](/ru/docs/scripting/examples/scoreboard).

<Callout type="info">
Выключите **CanNetworkSteal** у компонента синхронизации, если другие игроки не должны иметь возможности выхватить пистолет из чужой руки.
</Callout>
