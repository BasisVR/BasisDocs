---
title: 示例
description: 常见世界和道具功能的完整可复制脚本，从旋转的立方体到联网的计分板。
---

每个示例都是一个完整的脚本，并附有所需的场景设置。它们循序渐进：如果您刚接触 Basis 脚本，请从**基础**开始，然后通过**同步开关**编写您的第一个联网脚本。

| 示例 | 展示内容 |
| --- | --- |
| [基础](/cn/docs/scripting/examples/basics) | Cilbox 脚本、检查器字段、`Update`、UI 按钮。 |
| [同步开关](/cn/docs/scripting/examples/synced-toggle) | 为所有人（包括后加入者）打开或关闭某样东西的按钮。 |
| [计分板](/cn/docs/scripting/examples/scoreboard) | 由一位所有者维护的同步分数，其他玩家请求所有者加分。 |
| [拾取枪](/cn/docs/scripting/examples/pickup-gun) | 可以开火的同步拾取物，射击效果对所有人可见。 |
| [触摸按钮](/cn/docs/scripting/examples/touch-button) | 在 VR 中用手指按下按钮。 |
| [座位](/cn/docs/scripting/examples/seats) | 通过脚本让玩家就座、转向和弹出。 |
| [区域与传送器](/cn/docs/scripting/examples/zones-and-teleporters) | 检测本地玩家是否在某个区域内、传送、蹦床和大厅人数。 |
| [NPC 跟随](/cn/docs/scripting/examples/npc-follow) | 由一位所有者模拟并发送给所有人的 NavMesh 代理。 |
| [图片加载](/cn/docs/scripting/examples/image-loading) | 在标牌上显示来自 URL 的图片。 |
| [小地图](/cn/docs/scripting/examples/minimap) | 跟随本地玩家、渲染到渲染纹理上的俯视摄像机。 |
| [持久化](/cn/docs/scripting/examples/persistence) | 保存和加载玩家的进度。 |
| [设置标签页](/cn/docs/scripting/examples/settings-tab) | 将世界选项添加到玩家的菜单中。 |
| [昼夜循环](/cn/docs/scripting/examples/day-night-cycle) | 基于共享服务器时钟的太阳，无需网络。 |
| [回合计时器](/cn/docs/scripting/examples/round-timer) | 每回合只需一条消息的同步倒计时。 |
| [知识问答](/cn/docs/scripting/examples/trivia-quiz) | 来自 JSON 文件的问题，并同步当前问题。 |
| [服务器最佳时间](/cn/docs/scripting/examples/server-best-time) | 使用 `BasisServerStorageShim` 在服务器上保存每位玩家的数据。 |
| [员工门](/cn/docs/scripting/examples/staff-door) | 供管理员和版主使用、实时更新的门。 |
| [语音舞台](/cn/docs/scripting/examples/voice-stage) | 通过舞台扬声器播放演讲者的语音。 |
| [画板](/cn/docs/scripting/examples/drawing-board) | 带有压缩后加入者快照的共享白板。 |
| [随机战利品](/cn/docs/scripting/examples/random-loot) | 无需消息即可让所有人得到相同的随机物品。 |
| [电梯](/cn/docs/scripting/examples/elevator) | 由一个同步数值驱动的共享移动平台。 |
| [尾巴反应](/cn/docs/scripting/examples/tail-reaction) | 虚拟形象的 jiggle 骨骼被抓住时做出反应。 |
| [手电筒](/cn/docs/scripting/examples/hand-flashlight) | 将物体无延迟地固定在手上。 |
| [桌面与 VR 输入](/cn/docs/scripting/examples/desktop-and-vr-input) | 一个脚本同时处理鼠标点击和 VR 扳机。 |
| [本地化标牌](/cn/docs/scripting/examples/localized-sign) | 以玩家的语言显示文本。 |
| [性能调节器](/cn/docs/scripting/examples/performance-scaler) | 在帧率下降时削减特效。 |
| [服务器传送门](/cn/docs/scripting/examples/server-portal) | 将玩家送往另一台服务器。 |
| [鸟群](/cn/docs/scripting/examples/boids) | 每帧通过一次批量调用为 200 只鸟制作动画。 |

所有示例也可以在 Unity 编辑器的 **Basis > Creator Guide** 中找到，每个代码块都带有复制按钮。
