## Zone für den lokalen Spieler

Die Position des lokalen Spielers regelmäßig mit den Bounds eines Triggers abzugleichen funktioniert in nativen und Cilbox-Skripten gleich und hängt nicht von Physik-Layern ab.

```csharp title="LocalPlayerZone.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class LocalPlayerZone : MonoBehaviour
{
    public Collider area;
    public GameObject showWhileInside;
    bool inside;

    void Start()
    {
        showWhileInside.SetActive(false);
    }

    void Update()
    {
        BasisLocalPlayer local = BasisLocalPlayer.Instance;
        if (local == null) return;
        local.GetPositionAndRotation(out Vector3 position, out Quaternion rotation);
        bool now = area.bounds.Contains(position);
        if (now == inside) return;
        inside = now;
        showWhileInside.SetActive(inside);
    }
}
```

<Callout type="info">
Für Bewegungsänderungen innerhalb eines Bereichs (geringe Schwerkraft, Fliegen, schnelleres Gehen) verwenden Sie die Komponente **Basis Locomotion Zone** aus com.basis.examples. Sie benötigt keinen Code.
</Callout>

## Teleporter

Fügen Sie das Skript einer Plattform oder einem Button hinzu. Teleportieren betrifft nur den lokalen Spieler, daher ist kein Networking nötig: Jeder Spieler teleportiert sich selbst.

```csharp title="Teleporter.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Teleporter : MonoBehaviour
{
    public Collider pad;
    public Transform destination;
    bool wasOnPad;

    void Update()
    {
        BasisLocalPlayer local = BasisLocalPlayer.Instance;
        if (local == null) return;
        local.GetPositionAndRotation(out Vector3 position, out Quaternion rotation);
        bool onPad = pad.bounds.Contains(position);
        if (onPad && !wasOnPad) TeleportNow();
        wasOnPad = onPad;
    }

    public void TeleportNow()
    {
        BasisLocalPlayer.Instance.Teleport(destination.position, destination.rotation, BasisTeleportMode.Instant);
    }
}
```

## Trampolin

`BasisVelocityShim` ist in Welten verfügbar. Behalten Sie die horizontale Geschwindigkeit bei und ersetzen Sie den Fall durch einen Sprung.

```csharp title="Trampoline.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Trampoline : MonoBehaviour
{
    public Collider surface;
    public float bounce = 9f;

    void Update()
    {
        BasisLocalPlayer local = BasisLocalPlayer.Instance;
        if (local == null) return;
        local.GetPositionAndRotation(out Vector3 position, out Quaternion rotation);
        if (!surface.bounds.Contains(position)) return;
        Vector3 velocity = BasisVelocityShim.Velocity;
        if (velocity.y > 0.5f) return;
        BasisVelocityShim.SetVelocity(new Vector3(velocity.x, bounce, velocity.z));
    }
}
```

## Lobby-Zähler

Zeigen Sie an, wie viele Spieler in einem Lobby-Bereich stehen. Jeder Client zählt selbst anhand der Spielerpositionen, daher sind keine Nachrichten nötig.

```csharp title="LobbyCounter.cs (Cilbox)"
using Basis.Scripts.BasisSdk.Players;
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class LobbyCounter : MonoBehaviour
{
    public Transform center;
    public float radius = 4f;
    public int needed = 4;
    public TextMeshPro label;
    float nextCheck;

    void Update()
    {
        if (Time.time < nextCheck) return;
        nextCheck = Time.time + 0.5f;
        int count = 0;
        foreach (IBasisPlayer player in BasisPlayersShim.Within(center.position, radius)) count++;
        label.text = count >= needed ? "Ready!" : $"{count} / {needed} players";
    }
}
```

Zweimal pro Sekunde statt in jedem Frame zu prüfen reicht für ein Schild völlig aus.
