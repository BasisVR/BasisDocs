## Configurazione

1. Modella o importa una pistola. Aggiungi un collider e un **Rigidbody**.
2. Aggiungi **Basis Pickup Interactable**.
3. Aggiungi **Basis Pickup Sync Networking** e assegna il pickup. Questo sincronizza la posizione della pistola e chi la tiene.
4. Aggiungi un **AudioSource** e un **ParticleSystem** per la vampata dello sparo, e un transform figlio sulla bocca della canna.
5. Aggiungi **PickupGun** e assegna tutto.

## Script

```csharp title="PickupGun.cs (Cilbox)"
using Basis;
using Basis.Network.Core;
using Basis.Scripts.BasisSdk.Interactions;
using Basis.Scripts.Device_Management.Devices;
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class PickupGun : MonoBehaviour
{
    public BasisPickupInteractable pickup;
    public Transform muzzle;
    public AudioSource shotSound;
    public ParticleSystem flash;
    public float range = 50f;
    public float cooldown = 0.2f;

    BasisNetworkShim net;
    bool held;
    float nextShot;

    void Start()
    {
        net = GetComponent<BasisNetworkShim>();
        net.NetworkMessageReceived += OnMessage;
        pickup.OnInteractStartEvent.AddListener(OnGrab);
        pickup.OnInteractEndEvent.AddListener(OnDrop);
        pickup.OnPickupUse.AddListener(OnUse);
    }

    void OnDestroy()
    {
        if (net != null) net.NetworkMessageReceived -= OnMessage;
    }

    void OnGrab(BasisInput input) { held = true; }
    void OnDrop(BasisInput input) { held = false; }

    void OnUse(BasisPickUpUseMode mode)
    {
        if (!held || mode != BasisPickUpUseMode.OnPickUpUseDown || Time.time < nextShot) return;
        nextShot = Time.time + cooldown;

        PlayShot();
        BasisHapticsShim.Play(this, BasisHapticHand.Both, 0.6f, 0.08f);
        if (net.HasNetworkID) net.SendCustomNetworkEvent(new byte[] { 1 }, DeliveryMethod.ReliableUnordered);

        if (Physics.Raycast(muzzle.position, muzzle.forward, out RaycastHit hit, range))
        {
            Debug.Log($"hit {hit.collider.name}");
        }
    }

    void OnMessage(ushort sender, byte[] buffer, DeliveryMethod method)
    {
        if (buffer != null && buffer.Length == 1 && buffer[0] == 1) PlayShot();
    }

    void PlayShot()
    {
        shotSound.Play();
        flash.Play();
    }
}
```

## Come funziona

- **Basis Pickup Sync Networking** prende l'ownership quando viene afferrato e trasmette la posa della pistola, così tutti la vedono nella mano di chi la tiene. Per questa parte non serve codice.
- **Il colpo è un evento**, non uno stato. Nessuno che entra dopo ha bisogno di sapere che è stato sparato un colpo, quindi non c'è gestione dei giocatori arrivati in ritardo.
- **Solo chi spara esegue il raycast.** I risultati dei colpi che contano per il gameplay (danni, punteggio) dovrebbero essere decisi da chi spara e inviati come evento separato, oppure indirizzati a un proprietario come nel [Tabellone segnapunti](/it/docs/scripting/examples/scoreboard).

<Callout type="info">
Disattiva **CanNetworkSteal** sul componente di sincronizzazione se gli altri giocatori non devono poter strappare la pistola dalla mano di qualcuno.
</Callout>
