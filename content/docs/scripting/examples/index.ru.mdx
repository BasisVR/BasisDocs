---
title: Примеры
description: Готовые скрипты для копирования, реализующие типичные функции миров и пропов, от вращающегося куба до сетевого табло.
---

Каждый пример это целый скрипт вместе с нужной ему настройкой сцены. Они опираются друг на друга: начните с **Основ**, если вы впервые пишете скрипты для Basis, затем перейдите к **Синхронизированному переключателю** для вашего первого сетевого скрипта.

| Пример | Что показывает |
| --- | --- |
| [Основы](/ru/docs/scripting/examples/basics) | Скрипт Cilbox, поля инспектора, `Update`, кнопка UI. |
| [Синхронизированный переключатель](/ru/docs/scripting/examples/synced-toggle) | Кнопка, которая включает или выключает что-то для всех, включая поздно подключившихся. |
| [Табло](/ru/docs/scripting/examples/scoreboard) | Синхронизированный счёт, который ведёт один владелец, а другие игроки просят владельца добавить очки. |
| [Пистолет-предмет](/ru/docs/scripting/examples/pickup-gun) | Синхронизированный подбираемый предмет, который стреляет, а выстрел видят все. |
| [Сенсорная кнопка](/ru/docs/scripting/examples/touch-button) | Нажатие кнопки пальцем в VR. |
| [Сиденья](/ru/docs/scripting/examples/seats) | Посадка, поворот и высаживание игроков из скрипта. |
| [Зоны и телепорты](/ru/docs/scripting/examples/zones-and-teleporters) | Определение локального игрока в области, телепортация, батуты и подсчёт игроков в лобби. |
| [NPC, следующий за игроком](/ru/docs/scripting/examples/npc-follow) | Агент NavMesh, который симулирует один владелец и передаёт всем. |
