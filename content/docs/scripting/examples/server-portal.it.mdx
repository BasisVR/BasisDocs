---
title: Portale verso un server
description: Un portale che propone al giocatore di spostarsi su un altro server Basis, usando BasisConnectionShim.
---

```csharp title="ServerPortal.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class ServerPortal : MonoBehaviour
{
    public string host = "play.example.com";
    public int port = 4296;
    public TextMeshPro sign;

    void Start()
    {
        GetComponent<BasisInteractableShim>().ButtonDown += OnPressed;
        sign.text = host;
    }

    void OnPressed()
    {
        BasisConnectionShim.RequestConnect(this, host, port, null, result =>
        {
            if (result == BasisConnectionResult.Declined) sign.text = "Maybe next time";
            else if (result != BasisConnectionResult.Accepted) sign.text = $"Can't connect: {result}";
        });
    }
}
```

- La richiesta deve partire da una pressione del giocatore stesso, e il giocatore vede sempre l'indirizzo e conferma.
- Per i server privati, passa una password come quarto argomento.
