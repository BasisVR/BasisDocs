---
title: Puerta del personal
description: Una puerta que solo se abre para administradores y moderadores, y que se actualiza en directo cuando cambian los roles.
---

```csharp title="StaffDoor.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class StaffDoor : MonoBehaviour
{
    public GameObject door;
    public GameObject staffSign;

    void Start()
    {
        GetComponent<BasisPermissionEventShim>();
    }

    void OnLocalPermissionsChanged(bool isAdmin, bool isModerator)
    {
        bool staff = isAdmin || isModerator;
        door.SetActive(!staff);
        staffSign.SetActive(staff);
    }
}
```

- La puerta se desactiva para el personal en su propio cliente. No afecta a nadie más, así que no se sincroniza nada por red.
- Para mostrar una insignia sobre *otros* miembros del personal, pregunte con `BasisPermissionsShim.IsModerator(player, callback)`; requiere un viaje de ida y vuelta al servidor.
- Las comprobaciones del lado del cliente mantienen fuera a los jugadores honestos. No confíe en ellas para nada a lo que un cliente modificado no deba llegar.
