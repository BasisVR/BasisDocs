## Настройка

1. Создайте **Quad** для таблички и назначьте ему материал с текстурным слотом (unlit или lit).
2. Добавьте **RemoteImage** и назначьте рендерер. Укажите URL и, при желании, текстуру-заглушку.

## Скрипт

```csharp title="RemoteImage.cs (Cilbox)"
using Basis;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class RemoteImage : MonoBehaviour
{
    public string url = "https://example.com/poster.png";
    public Renderer target;
    public Texture placeholder;
    public float refreshMinutes = 0f;

    float nextRefresh;

    void Start()
    {
        if (placeholder != null) target.material.mainTexture = placeholder;
        Load();
    }

    void Update()
    {
        if (refreshMinutes <= 0f || Time.time < nextRefresh) return;
        Load();
    }

    void Load()
    {
        nextRefresh = Time.time + refreshMinutes * 60f;
        var downloader = new BasisImageDownloader();
        downloader.DownloadImage(url, result =>
        {
            if (result.Success) target.material.mainTexture = result.Result;
            else Debug.LogWarning($"poster failed: {result.Error}");
        });
    }
}
```

## Правила

- Только https. Обычный http, IP-адреса и всё, что разрешается в адрес локальной сети, отклоняются ещё до отправки запроса.
- Без перенаправлений. Размещайте изображение по его конечному адресу.
- Игроки одобряют хосты. Когда контент впервые запрашивает новый хост, игрок получает запрос. Пока он не согласится, загрузка завершается ошибкой и остаётся ваша заглушка.
- Каждый игрок загружает изображение сам; синхронизировать ничего не нужно. Чтобы у всех отображалось одно и то же меняющееся изображение, синхронизируйте **индекс URL** (шаблон см. в [Синхронизированный переключатель](/ru/docs/scripting/examples/synced-toggle)) и загружайте локально.

<Callout type="info">
Для текста используйте `BasisStringDownloader.DownloadString` с теми же правилами, а для чтения JSON используйте `BasisJson.Parse`.
</Callout>
