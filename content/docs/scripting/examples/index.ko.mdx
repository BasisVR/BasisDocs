각 예제는 필요한 씬 설정과 함께 제공되는 완전한 스크립트입니다. 예제들은 서로를 기반으로 합니다. Basis 스크립팅이 처음이라면 **기본**부터 시작하고, 첫 네트워크 스크립트로 **동기화 토글**을 보세요.

| 예제 | 보여주는 것 |
| --- | --- |

| [동기화 토글](/ko/docs/scripting/examples/synced-toggle) | 늦게 참여한 플레이어를 포함해 모든 사람에게 무언가를 켜거나 끄는 버튼. |
| [점수판](/ko/docs/scripting/examples/scoreboard) | 한 명의 소유자가 관리하는 동기화 점수. 다른 플레이어는 소유자에게 점수 추가를 요청합니다. |
| [픽업 총](/ko/docs/scripting/examples/pickup-gun) | 발사가 가능한 동기화 픽업. 발사가 모든 사람에게 보입니다. |

| [구역과 텔레포터](/ko/docs/scripting/examples/zones-and-teleporters) | 영역 안의 로컬 플레이어 감지, 텔레포트, 트램펄린, 로비 인원 수. |
