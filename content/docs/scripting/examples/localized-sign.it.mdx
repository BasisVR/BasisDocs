---
title: Cartello localizzato
description: Un cartello che mostra il testo nella lingua del giocatore e cambia in tempo reale quando la modifica, usando BasisLanguageEventShim.
---

```csharp title="LocalizedSign.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class LocalizedSign : MonoBehaviour
{
    public TextMeshPro label;
    public string[] languageCodes = { "en", "de", "fr", "ja" };
    public string[] texts = { "Welcome", "Willkommen", "Bienvenue", "ようこそ" };

    void Start()
    {
        GetComponent<BasisLanguageEventShim>();
    }

    void OnLanguageChanged(string code)
    {
        label.text = texts[0];
        for (int i = 0; i < languageCodes.Length; i++)
        {
            if (code.StartsWith(languageCodes[i])) { label.text = texts[i]; return; }
        }
    }
}
```

- `OnLanguageChanged` viene chiamato una volta subito con la lingua corrente.
- Il confronto con `StartsWith` permette a `es` di coprire `es-MX`.
- Imposta gli array nell'Inspector invece che con un inizializzatore se la tua sandbox rifiuta gli inizializzatori di array, e assicurati che il font abbia i glifi che ti servono.
