Это самый маленький законченный сетевой скрипт: один байт состояния, который отправляется при изменении и повторно отправляется каждому, кто подключается.

## Настройка

1. Создайте canvas в мировом пространстве с **Button**.
2. Добавьте **SyncedToggle** на canvas. Назначьте кнопку и объект для переключения (свет, зеркало, дверь).

## Скрипт

```csharp title="SyncedToggle.cs (Cilbox)"
using Basis;
using Basis.Network.Core;
using Basis.Scripts.Networking.NetworkedAvatar;
using Cilbox;
using UnityEngine;
using UnityEngine.UI;

[Cilboxable]
public class SyncedToggle : MonoBehaviour
{
    public Button button;
    public GameObject target;
    public bool startOn = true;

    BasisNetworkShim net;
    bool on;

    void Start()
    {
        on = startOn;
        Apply();
        button.onClick.AddListener(OnPressed);
        net = SafeUtil.MakeNetworkable(this);
        net.NetworkMessageReceived += OnMessage;
        net.PlayerJoined += OnPlayerJoined;
    }

    void OnDestroy()
    {
        button.onClick.RemoveAllListeners();
        if (net == null) return;
        net.NetworkMessageReceived -= OnMessage;
        net.PlayerJoined -= OnPlayerJoined;
    }

    void OnPressed()
    {
        net.TakeOwnership();
        on = !on;
        Apply();
        Send(null);
    }

    void OnMessage(ushort sender, byte[] buffer, DeliveryMethod method)
    {
        if (buffer == null || buffer.Length < 1) return;
        on = buffer[0] != 0;
        Apply();
    }

    void OnPlayerJoined(BasisNetworkPlayer player)
    {
        if (net.HasNetworkID && net.IsOwnedLocallyOnServer) Send(new[] { player.playerId });
    }

    void Send(ushort[] recipients)
    {
        if (!net.HasNetworkID) return;
        net.SendCustomNetworkEvent(new[] { on ? (byte)1 : (byte)0 }, DeliveryMethod.ReliableOrdered, recipients);
    }

    void Apply()
    {
        target.SetActive(on);
    }
}
```

## Как это работает

- Нажатие берёт владение, меняет значение локально, чтобы нажавший сразу увидел результат, и отправляет новое значение всем остальным.
- `ReliableOrdered` гарантирует, что каждое изменение дойдёт, и в правильном порядке. Все объекты сцены используют один общий сетевой канал, поэтому с `ReliableSequenced` сообщение другого объекта, отправленное сразу после этого, могло бы его заменить, и переключение потерялось бы.
- Подключающийся игрок получает текущее значение только от владельца. Поскольку сообщение содержит всё состояние, один и тот же `OnMessage` обрабатывает и живые изменения, и наверстывание.

<Callout type="info">
Нативная версия: наследуйтесь от `BasisNetworkBehaviour`, замените события шима переопределениями `OnNetworkMessage` и `OnPlayerJoined` и вызывайте `TakeOwnership()` и `SendCustomNetworkEvent` напрямую.
</Callout>
