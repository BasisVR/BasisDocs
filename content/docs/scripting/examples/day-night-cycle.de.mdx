---
title: Tag-Nacht-Zyklus
description: Eine Sonne, die sich nach der Serveruhr bewegt, sodass jeder Spieler ohne Networking-Code dieselbe Tageszeit sieht.
---

Ein Tageszyklus, der von `Time.time` gesteuert wird, läuft bei Spielern auseinander, die zu unterschiedlichen Zeitpunkten beigetreten sind. Wenn Sie ihn über die Serveruhr steuern, bleiben alle ohne Aufwand synchron.

```csharp title="DayNightCycle.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class DayNightCycle : MonoBehaviour
{
    public Light sun;
    public float minutesPerDay = 24f;
    public Gradient skyColor;

    void Update()
    {
        double seconds = BasisNetworkTimeShim.ServerTimeSeconds;
        float day = minutesPerDay * 60f;
        float t = (float)(seconds % day / day);
        sun.transform.rotation = Quaternion.Euler(t * 360f - 90f, 30f, 0f);
        sun.intensity = Mathf.Clamp01(Mathf.Sin(t * Mathf.PI * 2f) * 2f);
        RenderSettings.ambientLight = skyColor.Evaluate(t);
    }
}
```

- Keine Ownership und kein Late-Joiner-Code: Die Uhr ist der gemeinsame Zustand.
- Aktualisieren Sie die Sonne in einer aufwendigen Szene nur einige Male pro Sekunde statt in jedem Frame.
