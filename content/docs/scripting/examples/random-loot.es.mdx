---
title: Botín aleatorio
description: Un cofre de botín que muestra a todos los jugadores el mismo objeto aleatorio sin enviar ningún mensaje, usando BasisSharedRandomShim.
---

```csharp title="LootChest.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class LootChest : MonoBehaviour
{
    public GameObject[] items;
    public int seed = 1234;
    public double refreshSeconds = 600d;
    long shownWindow = -1;

    void Update()
    {
        long window = BasisSharedRandomShim.WindowIndex(refreshSeconds);
        if (window == shownWindow) return;
        shownWindow = window;
        int pick = BasisSharedRandomShim.RangeInt(seed, window, 0, items.Length);
        for (int i = 0; i < items.Length; i++) items[i].SetActive(i == pick);
    }
}
```

- Cada 10 minutos de tiempo del servidor el cofre vuelve a sortear, y todos los clientes obtienen el mismo objeto.
- Dé a cada cofre su propia `seed` para que no muestren todos lo mismo.
- Para un sorteo que activa un jugador, envíe solo el número de ronda como evento de red y deje que cada cliente calcule `RangeInt(seed, round, ...)`.
