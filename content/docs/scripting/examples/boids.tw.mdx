---
title: Boids
description: 透過 BasisTransformBatchShim 批次寫入 transform，在 Cilbox 中以低成本驅動 200 隻鳥的鳥群動畫。
---

從 Cilbox 腳本逐一移動 200 個 transform，每幀要耗費數百次直譯呼叫。批次處理則讓它只需一次。

```csharp title="Flock.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Flock : MonoBehaviour
{
    public Transform[] birds;
    public float radius = 10f;
    public float speed = 0.4f;

    float[] xyz;
    float[] phase;

    void Start()
    {
        xyz = new float[birds.Length * 3];
        phase = new float[birds.Length];
        for (int i = 0; i < phase.Length; i++) phase[i] = i * 0.37f;
    }

    void Update()
    {
        float t = Time.time * speed;
        Vector3 c = transform.position;
        float cx = c.x, cy = c.y, cz = c.z;
        for (int i = 0; i < birds.Length; i++)
        {
            float a = t + phase[i];
            xyz[i * 3] = cx + Mathf.Cos(a) * radius;
            xyz[i * 3 + 1] = cy + Mathf.Sin(a * 2f) * 2f;
            xyz[i * 3 + 2] = cz + Mathf.Sin(a) * radius;
        }
        BasisTransformBatchShim.SetPositions(birds, xyz);
    }
}
```

- 數學運算在純 float 上執行，在直譯器中比 `Vector3` 運算子便宜得多。
- `SetPositions(Transform[], float[])` 會在一次原生呼叫中寫入每一隻鳥。
- 如果鳥群必須在玩家之間完全對齊，請將 `Time.time * speed` 替換為 `(float)(BasisNetworkTimeShim.ServerTimeSeconds * speed % (2d * Mathf.PI))`。請在數值仍是 `double` 時取餘數：伺服器時間對 `float` 來說太大了，鳥群會靜止不動。
