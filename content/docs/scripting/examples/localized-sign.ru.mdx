---
title: Локализованная табличка
description: Табличка, которая показывает текст на языке игрока и переключается сразу, когда он его меняет, с помощью BasisLanguageEventShim.
---

```csharp title="LocalizedSign.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class LocalizedSign : MonoBehaviour
{
    public TextMeshPro label;
    public string[] languageCodes = { "en", "de", "fr", "ja" };
    public string[] texts = { "Welcome", "Willkommen", "Bienvenue", "ようこそ" };

    void Start()
    {
        GetComponent<BasisLanguageEventShim>();
    }

    void OnLanguageChanged(string code)
    {
        label.text = texts[0];
        for (int i = 0; i < languageCodes.Length; i++)
        {
            if (code.StartsWith(languageCodes[i])) { label.text = texts[i]; return; }
        }
    }
}
```

- `OnLanguageChanged` вызывается один раз сразу же с текущим языком.
- Сравнение через `StartsWith` позволяет `es` охватить и `es-MX`.
- Если ваша песочница отклоняет инициализаторы массивов, задайте массивы в инспекторе, и убедитесь, что в шрифте есть нужные глифы.
