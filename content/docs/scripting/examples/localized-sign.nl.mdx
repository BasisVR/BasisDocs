---
title: Gelokaliseerd bord
description: Een bord dat tekst in de taal van de speler toont en live wisselt wanneer die de taal verandert, met BasisLanguageEventShim.
---

```csharp title="LocalizedSign.cs (Cilbox)"
using Basis.Shims;
using Cilbox;
using TMPro;
using UnityEngine;

[Cilboxable]
public class LocalizedSign : MonoBehaviour
{
    public TextMeshPro label;
    public string[] languageCodes = { "en", "de", "fr", "ja" };
    public string[] texts = { "Welcome", "Willkommen", "Bienvenue", "ようこそ" };

    void Start()
    {
        GetComponent<BasisLanguageEventShim>();
    }

    void OnLanguageChanged(string code)
    {
        label.text = texts[0];
        for (int i = 0; i < languageCodes.Length; i++)
        {
            if (code.StartsWith(languageCodes[i])) { label.text = texts[i]; return; }
        }
    }
}
```

- `OnLanguageChanged` wordt meteen één keer aangeroepen met de huidige taal.
- Door te vergelijken met `StartsWith` valt `es-MX` ook onder `es`.
- Stel de arrays in de inspector in in plaats van met een initializer als je sandbox array-initializers weigert, en zorg dat het lettertype de tekens bevat die je nodig hebt.
