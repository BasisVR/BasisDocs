Basis выполняет код двумя способами. Какой из них использовать, зависит от того, **где находится скрипт**: внутри приложения, которое вы собираете, или внутри контента, загружаемого во время работы.

## Native: скомпилирован в приложение

Нативный скрипт представляет собой обычный Unity `MonoBehaviour`, встроенный в клиент Basis (или в ваше собственное приложение на фреймворке Basis). Он компилируется вместе с приложением, поэтому поставляется со следующей сборкой клиента, а не с миром или пропом.

- Полный C# и полный API Unity и Basis.
- Полная нативная скорость.
- Может наследоваться от классов Basis, таких как `BasisNetworkBehaviour` и `BasisSyncedObject`.
- Существует только в клиентах, собранных с ним. У игроков на публичном клиенте вашего скрипта нет.

Используйте нативные скрипты, когда вы **создаёте приложение или игру на Basis**: собственные меню, игровые правила, системы и любые компоненты, на которые опирается ваш контент.

## Cilbox: скрипты внутри контента во время работы

Скрипт Cilbox представляет собой `MonoBehaviour` с атрибутом `[Cilboxable]`, который поставляется **внутри** `.bee`-файла мира, пропа или аватара. При загрузке контента Basis выполняет его в интерпретаторе Cilbox, внутри песочницы для данного типа контента (Scene, Prop или Avatar).

- Работает в любом клиенте Basis, загружающем контент. Сборка клиента не нужна.
- Песочница: можно вызывать только разрешённые типы и методы, поэтому контент не может навредить компьютеру игрока.
- Медленнее нативного кода, потому что код интерпретируется.
- Использует шимы вместо базовых классов, например `BasisNetworkShim` вместо наследования от `BasisNetworkBehaviour`.

Используйте Cilbox, когда вы **создаёте пользовательский контент**: миры, пропы и аватары, которые загружают другие люди.

## Кратко

| | Native | Cilbox |
| --- | --- | --- |
| Где находится | В сборке приложения | В мире, пропе или аватаре |
| Когда загружается | При сборке приложения | Во время работы, вместе с контентом |
| Помечается | Ничем | `[Cilboxable]` |
| API | Всё | Белый список для каждой песочницы |
| Скорость | Нативная | Интерпретируемая, намного медленнее |
| Сеть | Наследование от `BasisNetworkBehaviour` | Использование `BasisNetworkShim` |
| У кого есть | У игроков на вашей сборке | У всех, кто загружает контент |

## Один и тот же скрипт обоими способами

```csharp title="Native"
using Basis;
using Basis.Network.Core;

public class Door : BasisNetworkBehaviour
{
    public override void OnNetworkMessage(ushort sender, byte[] buffer, DeliveryMethod method)
    {
        gameObject.SetActive(buffer[0] != 0);
    }
}
```

```csharp title="Cilbox"
using Basis;
using Basis.Network.Core;
using Cilbox;
using UnityEngine;

[Cilboxable]
public class Door : MonoBehaviour
{
    BasisNetworkShim net;

    void Start()
    {
        net = GetComponent<BasisNetworkShim>();
        net.NetworkMessageReceived += OnMessage;
    }

    void OnMessage(ushort sender, byte[] buffer, DeliveryMethod method)
    {
        gameObject.SetActive(buffer[0] != 0);
    }
}
```

## Как поставлять каждый вариант

- **Native:** добавьте скрипт в проект Unity и соберите клиент. Если нативный компонент размещён внутри бандла мира или пропа, добавьте его тип также в соответствующий селектор content police, иначе он будет удалён при загрузке контента (см. [Разрешённые компоненты](/ru/docs/scripting/allowed-components)).
- **Cilbox:** добавьте в контент **Cilbox Scene Basis** (мир) или **Cilbox Prop Basis** (проп), пометьте скрипты `[Cilboxable]` и соберите `.bee` как обычно. См. [Основы](/ru/docs/scripting/examples/basics).

<Callout type="info">
Примеры в этой документации помечены как **Native** или **Cilbox**. Большинство примеров Cilbox также компилируются как нативные скрипты; нативные примеры обычно требуют изменений для работы в Cilbox. Правила, на которые стоит обратить внимание, описаны в разделе [Правила песочницы](/ru/docs/scripting/sandbox-rules).
