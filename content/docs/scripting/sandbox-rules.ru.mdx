Cilbox интерпретирует скомпилированный код вашего скрипта внутри песочницы. Большая часть C# работает, но на этих правилах хотя бы раз спотыкается почти каждый.

## Жизненный цикл

- **Нет `LateUpdate`, `OnGUI`, `OnAnimatorIK`, `OnParticleCollision` и корутин.** Используйте `Update` и [отложенные события](/ru/docs/scripting/common-usages#timers-and-delayed-events).
- **Первый `OnEnable` теряется.** Выполняйте настройку в `Start`, а очистку в `OnDestroy`.
- **Не наследуйтесь от `BasisNetworkBehaviour`.** Прокси, заменяющий ваш скрипт, им не является. Используйте `BasisNetworkShim` (см. [Сетевые события](/ru/docs/scripting/networking/network-events#cilbox)).

## Структуры общие, а не копируются

Копирование структуры Unity (`Vector3`, `Quaternion`, `Color`) в переменную разделяет одно и то же значение. Изменение поля у копии меняет оригинал.

```csharp
// Wrong: also moves `target`.
Vector3 p = target;
p.y = 0f;

// Right: build a new value.
Vector3 p = new Vector3(target.x, 0f, target.z);
```

- `points[i].x = 5f` для массива молча теряется. Пишите `points[i] = new Vector3(5f, points[i].y, points[i].z)`.
- `points[i] += offset` выбрасывает исключение. Пишите `points[i] = points[i] + offset`.
- Значения из вызовов и операторов Unity (`a + b`, `transform.position`, `new Vector3(...)`) новые, и их безопасно изменять.

## Вызовы и разрешения

- **Разрешённый тип допускает все свои публичные методы**, если только для этого типа нет ограничения по методам. **Поля запрещены**, если они не перечислены.
- **Типы параметров, обобщений и возвращаемых значений тоже проверяются.** Вызов может пройти проверку по имени и всё равно быть отклонён из-за одного из своих типов.
- **`this.GetComponent` работает всегда.** `gameObject.GetComponent` ограничен, а песочница пропов не позволяет обходить с его помощью иерархию.
- **`AddComponent`, `SendMessage` и `BroadcastMessage` всегда заблокированы.** Cilbox сам добавляет `BasisNetworkShim` и шимы событий при вызове `GetComponent`.
- **`Debug.DrawLine` и `Debug.DrawRay` не существуют** в `Debug` песочницы, и обращение к ним не даёт загрузиться ни одному скрипту в контенте.
- **Константы бесплатны.** Для `const` не нужна запись в белом списке.

## События и делегаты

Каждый раз, когда вы используете метод как делегат, создаётся новая обёртка, поэтому `-=` может не удалить добавленную. Для издателей, которые живут дольше вашего скрипта, опрашивайте значение в `Update` вместо подписки.

## Content police

Любой компонент в вашем контенте, который не помечен `[Cilboxable]` и не входит в список разрешённых, **уничтожается при загрузке**. Конвертация скрипта и разрешение компонента делаются отдельно. См. [Разрешённые компоненты](/ru/docs/scripting/allowed-components).

## Скрипты аватаров выполняются на компьютере у каждого

Каждый скрипт Cilbox на аватаре выполняется на каждом клиенте, который загружает аватар, в пределах лимита поведений на аватар. Ограничивайте логику только для владельца проверкой `avatar.IsOwnedLocally` (см. [Скрипты аватаров](/ru/docs/scripting/avatar-scripting)).

## Производительность

Интерпретируемый код намного медленнее нативного. Примерные затраты на настольном ПК:

| Операция | Затраты |
| --- | --- |
| Простая арифметика с float | ~15 нс |
| Вызов одного из ваших методов | ~270 нс |
| Оператор `Vector3` (`a + b`) | ~1,7 мкс, плюс мусор |
| Вызов Unity, например `Mathf.Sqrt` | ~0,9 мкс |

Поэтому:

- **Выполняйте работу по событиям, а не каждый кадр.** Проверяйте таймеры, расстояния и UI несколько раз в секунду.
- **Предпочитайте float вместо математики `Vector3` в циклах.** Векторная математика в горячем цикле примерно в 100 раз медленнее той же математики на отдельных float.
- **Перекладывайте тяжёлую работу на компоненты.** Аниматоры, системы частиц, физика и констрейнты работают нативно.
- **Используйте пулы объектов** вместо вызова `Instantiate` при каждом выстреле.
- **Объединяйте работу с трансформами.** `BasisTransformSyncShim` читает, записывает или копирует целые массивы трансформов за один вызов, а `BasisBlendShapeSyncShim` делает то же самое для блендшейпов.

<Callout type="info">
**Basis > Tools > Cilbox Permissions** показывает белый список каждой песочницы, а его вкладка **Script Check** проверяет ваши скрипты на заблокированные вызовы перед загрузкой.
</Callout>
