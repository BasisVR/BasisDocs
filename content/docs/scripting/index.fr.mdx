## Vue d'ensemble

Les scripts fournissent des fonctionnalités avancées dans le framework Basis. Cette documentation vous guidera dans la création, la compilation et le test de scripts avec Unity et le SDK Basis.

## Native et Cilbox

Basis propose deux types de scripts :

- Les scripts **Native** sont compilés dans l'application. Ils disposent de l'API complète de Unity et de Basis et d'une vitesse native, mais n'existent que dans les clients compilés avec eux. Utilisez-les lorsque vous créez une application ou un jeu sur Basis.
- Les scripts **Cilbox** sont des scripts d'exécution. Ils sont livrés dans un monde, un prop ou un avatar, sont marqués `[Cilboxable]` et s'exécutent dans une sandbox sur tout client qui charge le contenu. Utilisez-les pour le contenu utilisateur.

Consultez [Native et Cilbox](/fr/docs/scripting/native-and-cilbox) pour la comparaison complète.
