## 概述

腳本在 Basis 框架內提供進階功能。本文件將引導您使用 Unity 和 Basis SDK 建立、編譯和測試腳本。

## Native 與 Cilbox

Basis 有兩種腳本：

- **Native** 腳本會編譯進應用程式中。它們擁有完整的 Unity 與 Basis API 以及原生速度，但只存在於包含它們一起建置的客戶端中。在 Basis 上開發應用程式或遊戲時請使用它們。
- **Cilbox** 腳本是執行階段腳本。它們隨世界、道具或虛擬形象一起發佈，標記為 `[Cilboxable]`，並在任何載入該內容的客戶端上於沙盒中執行。製作使用者內容時請使用它們。

完整比較請參閱 [Native 與 Cilbox](/tw/docs/scripting/native-and-cilbox)。
