内容加载时，Basis 的 **content police** 会移除所有类型不在该内容类型允许列表中的组件。标记了 `[Cilboxable]` 的脚本会先被转换为沙盒化的代理，因此能够保留下来。

## 允许列表

这些列表位于 `Packages/com.basis.sdk/Settings/`：

| 资源 | 适用于 |
| --- | --- |
| `SceneContentPoliceSelector` | 世界 |
| `PropContentPoliceSelector` | 道具 |
| `AvatarContentPoliceSelector` | 虚拟形象 |

每个资源都是完整类型名称的列表。匹配是精确的：允许类型的子类**不会**被允许，除非它本身也被列出。

## 默认允许的内容

**世界和道具**：渲染（网格、蒙皮网格、线条、拖尾、粒子和 LOD 组件、灯光、反射探针、摄像机）、物理（碰撞体、刚体、关节）、音频源和 Steam Audio、Animator 和动画、UI canvas 和 TextMesh Pro、`VideoPlayer`、VFX Graph 绑定器、AudioLink、Basis 约束、Basis 媒体播放器、镜子、座位、拾取物、`BasisSyncedTransform`、`BasisPickupSyncNetworking`、`BasisSeatSync`、载具、`BasisPlatformSwitch`，以及 Cilbox 沙盒和 shim。世界还允许导航（`NavMeshAgent`、`NavMeshObstacle`）、后处理体积和虚拟形象展台。

**虚拟形象**：渲染、物理、音频、Animator、约束、座位、同步变换、OSC 以及虚拟形象 shim。不允许摄像机、灯光、UI 或视频。

**默认不允许**（仅限客户端构建）：`BasisSyncedParameters`、`BasisSyncedRigidbody`、`BasisLocomotionZone`、`BasisRuntimeLoader`，以及您自己的任何 Native `MonoBehaviour`。

<Callout type="info">
选择器资源才是权威来源，并且会随版本变化。在检查器中打开它们即可查看当前列表。
</Callout>

## 检查您的内容

- 进入播放模式：Basis 会应用相同的检查，被移除的组件会记录在日志中。
- **Basis > Tools > Cilbox Permissions** 会列出每个沙盒允许脚本调用的内容。

## 添加组件（客户端构建）

如果您发布自己的客户端，请将该类型的完整名称添加到对应的选择器资源中。为公共客户端构建的内容不能依赖这一点；在那种情况下，请将逻辑转换为 `[Cilboxable]` 脚本。
