## Descripción general

Los scripts proporcionan funcionalidad avanzada dentro del framework Basis. Esta documentación le guiará en la creación, compilación y prueba de scripts usando Unity y el SDK de Basis.

## Native y Cilbox

Basis tiene dos tipos de scripts:

- Los scripts **Native** se compilan dentro de la aplicación. Tienen acceso completo a la API de Unity y de Basis y velocidad nativa, pero solo existen en los clientes compilados con ellos. Úselos cuando cree una aplicación o un juego sobre Basis.
- Los scripts **Cilbox** son scripts en tiempo de ejecución. Se incluyen dentro de un mundo, prop o avatar, están marcados con `[Cilboxable]` y se ejecutan en un sandbox en cualquier cliente que cargue el contenido. Úselos para contenido de usuario.

Consulte [Native y Cilbox](/es/docs/scripting/native-and-cilbox) para la comparación completa.
