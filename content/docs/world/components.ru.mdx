Эти компоненты это строительные блоки мира Basis. Ни одному из них не нужен код. Элементы с пометкой *(сборки клиента)* не входят в список разрешённого по умолчанию для загружаемого контента; смотрите [Разрешённые компоненты](/ru/docs/scripting/allowed-components).

## Обязательные

| Компонент | Что делает |
| --- | --- |
| **Basis Scene** | Помечает сцену как мир Basis. Задаёт **Spawn Point**, высоту **Respawn Height**, при падении ниже которой игроки возвращаются, группу аудиомикшера и основную камеру. Один на мир. Смотрите [Сборка](/ru/docs/world/building). |

## Взаимодействие

| Компонент | Что делает |
| --- | --- |
| **Basis Interactable Shim** | Делает объект нажимаемым из скрипта: `ButtonDown` и `ButtonUp`, с цветами наведения и нажатия. |
| **Basis Pickup Interactable** | Позволяет игрокам хватать, держать и использовать объект. Вызывает `OnPickupUse`, когда курок нажат во время удержания. |
| **Basis Interactable Button** | Готовая нажимаемая кнопка (com.basis.examples, префаб `ExampleInteractableButton`). |
| **Basis Seat** | Позволяет игрокам садиться. Ограничения вращения, режим подсветки и управление из скрипта через `TrySeatLocalPlayer`, `EjectLocalPlayer` и `IsAvailable`. |
| **Basis Avatar Pedestal** | Показывает аватар и позволяет игрокам переключиться на него. Только для миров. |
| **Basis Runtime Loader** *(сборки клиента)* | Создаёт пропы из load config, например по нажатию кнопки. Смотрите [Пропы сцены](/ru/docs/world/scene-props). |

## Сеть

| Компонент | Что делает |
| --- | --- |
| **Basis Pickup Sync Networking** | Синхронизирует позу подбираемого предмета и того, кто его держит. |
| **Basis Synced Transform** | Синхронизирует движущийся объект. **Basis Synced Rigidbody** *(сборки клиента)* добавляет скорости. |
| **Basis Synced Parameters** *(сборки клиента)* | Синхронизирует именованные значения (float, int, bool, цвета). |
| **Basis Seat Sync** | Синхронизирует, кто сидит на сиденье. |
| **Basis Networked Vehicle** | Синхронизированные управляемые транспортные средства, собранные из частей: корпус, колёса, двигатели и сиденье пилота. |

Смотрите [Сетевые компоненты](/ru/docs/scripting/networking/network-components).

## Медиа и рендеринг

| Компонент | Что делает |
| --- | --- |
| **Basis Media Player** | Синхронизированное воспроизведение видео и трансляций. Смотрите [Медиаплеер](/ru/docs/world/media-player). |
| **Basis SDK Mirror** | Зеркало. Задайте размер render texture, дальнюю плоскость отсечения и то, рендерится ли постобработка в отражении. Зеркала рендерят сцену повторно. Делайте их небольшими и выключенными по умолчанию. |
| **TextMesh Pro** | Текст на табличках и в UI. Поддерживается в мирах и в скриптах Cilbox. |
| **Canvas** | UI в мировом пространстве, который работает с указателем Basis. Смотрите [UI Canvas](/ru/docs/world/ui-canvas). |

## Игрок и платформа

| Компонент | Что делает |
| --- | --- |
| **Basis Locomotion Zone** *(сборки клиента)* | Меняет высоту прыжка, скорость ходьбы и бега, гравитацию или режим передвижения, пока локальный игрок находится внутри его триггера. |
| **Basis Platform Switch** | Включает или отключает объекты и компоненты для каждой платформы (VR, десктоп, мобильные) по списку правил. |

## Скрипты

| Компонент | Что делает |
| --- | --- |
| **Cilbox Scene Basis** / **Cilbox Prop Basis** | Песочница, в которой выполняются скрипты `[Cilboxable]` вашего мира или пропа. Смотрите [Скриптинг](/ru/docs/scripting/scripting). |
| **Basis OSC** | Публикация и подписка на сообщения OSC. Смотрите [OSC](/ru/docs/scripting/osc). |
| **Basis Action Trigger** | Передаёт события указателя UI (вход, выход, клик, перетаскивание) скрипту Cilbox. |

<Callout type="info">
Каждый компонент задокументирован в редакторе Unity: выберите его и нажмите кнопку документации в его инспекторе или откройте **Basis > Creator Guide**, чтобы читать это руководство офлайн.
</Callout>
