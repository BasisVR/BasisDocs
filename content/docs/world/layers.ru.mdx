Basis резервирует несколько слоёв Unity. Используйте их так, как описано, чтобы игроки, указатели и камеры правильно обращались с вашими объектами.

| # | Слой | Для чего используется |
| --- | --- | --- |
| 0 | Default | Обычная геометрия мира. Игроки сталкиваются с ней, указатели попадают в неё. |
| 1 | TransparentFX | Стандартный слой Unity. |
| 2 | Ignore Raycast | Указатели и лучи в него не попадают, камера от третьего лица его игнорирует. |
| 3 | Player | Character controller локального игрока. |
| 4 | Water | Стандартный слой Unity. |
| 5 | UI | UI в мировом пространстве. |
| 6 | LocalPlayerAvatar | Ваш собственный аватар. При необходимости скрывается из вида от первого лица. |
| 7 | RemotePlayerAvatar | Аватары других игроков. |
| 8 | Interactable | Объекты, которые указатель должен подсвечивать и с которыми может взаимодействовать. |
| 9 | OverlayUI | UI, рисуемый поверх всего, например меню. |
| 10 | IgnoredByInteractable | Видимый и твёрдый, но указатели проходят насквозь. Используйте для стекла или объёмов-триггеров перед кнопками. |
| 11 | HandHeldCameraUI | Собственный UI ручной камеры. |

## Выбор слоя

- **Стены, полы, пропы:** Default.
- **Объёмы-триггеры и невидимые преграды перед кнопками:** IgnoredByInteractable, чтобы указатели могли достать то, что за ними.
- **Декоративные коллайдеры, в которые указатель никогда не должен попадать:** Ignore Raycast.
- **Никогда не помещайте свои объекты на** Player, LocalPlayerAvatar, RemotePlayerAvatar или OverlayUI.

<Callout type="info">
Имена и номера слоёв берутся из Tag Manager проекта Basis. Контент собирается с ними, поэтому не переименовывайте и не меняйте порядок слоёв Basis в своём проекте.
</Callout>
