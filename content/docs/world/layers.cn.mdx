Basis 保留了若干 Unity 层。请按照说明使用它们，以便玩家、指针和摄像机正确处理您的物体。

| # | 层 | 用于 |
| --- | --- | --- |
| 0 | Default | 普通的世界几何体。玩家会与其碰撞，指针会命中它。 |
| 1 | TransparentFX | Unity 默认层。 |
| 2 | Ignore Raycast | 不会被指针或射线检测命中，并被第三人称摄像机忽略。 |
| 3 | Player | 本地玩家的角色控制器。 |
| 4 | Water | Unity 默认层。 |
| 5 | UI | 世界空间 UI。 |
| 6 | LocalPlayerAvatar | 您自己的虚拟形象。在需要时从第一人称视角中隐藏。 |
| 7 | RemotePlayerAvatar | 其他玩家的虚拟形象。 |
| 8 | Interactable | 指针应当高亮并与之交互的物体。 |
| 9 | OverlayUI | 绘制在所有内容之上的 UI，例如菜单。 |
| 10 | IgnoredByInteractable | 可见且有实体，但指针会穿过。用于按钮前方的玻璃或触发体积。 |
| 11 | HandHeldCameraUI | 手持摄像机自身的 UI。 |

## 选择层

- **墙壁、地面、道具**：Default。
- **按钮前方的触发体积和不可见阻挡物**：IgnoredByInteractable，这样指针可以到达它们后面的东西。
- **指针永远不应命中的装饰性碰撞体**：Ignore Raycast。
- **绝不要将您的物体放在** Player、LocalPlayerAvatar、RemotePlayerAvatar 或 OverlayUI 层上。

<Callout type="info">
层的名称和编号来自 Basis 项目的 Tag Manager。内容是基于它们构建的，因此不要在您的项目中重命名或重新排序 Basis 层。
</Callout>
