## Установка Unity

- Hub - https://unity.com/download
- Standalone - https://unity.com/releases/editor/archive

### Совместимые версии Unity

В зависимости от используемой ветки, пожалуйста, используйте версию редактора Unity, на которой основан фреймворк:

✓ [Developer](https://github.com/BasisVR/Basis/blob/developer/Basis/ProjectSettings/ProjectVersion.txt#L1)  
✓ [Long-Term-Support](https://github.com/BasisVR/Basis/blob/long-term-support/Basis/ProjectSettings/ProjectVersion.txt#L1)

### Дополнительные модули Unity

Добавьте следующие модули через экран «Добавить модули» при установке версии редактора Unity:

```ts tab="Windows"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (Mono) 
✓ Mac Build Support (Mono)
✓ Windows Build Support (IL2CPP)
```

```ts tab="Mac"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (Mono)
✓ Mac Build Support (IL2CPP)
✓ Windows Build Support (Mono)
```

```ts tab="Linux"
✓ Android Build Support  
   ↳ ✓ OpenJDK  
   ↳ ✓ Android SDK & NDK Tools  
✓ IOS Build Support  
✓ Linux Build Support (IL2CPP)
✓ Mac Build Support (Mono)
✓ Windows Build Support (Mono)
```

<Callout type="info">
Даже если вы создаёте только пользовательский контент для аватаров и миров, вам всё равно потребуются эти дополнительные модули для обеспечения доступности контента на этих платформах.
</Callout>

<Callout type="info">
Если у вас уже установлена правильная версия Unity, но опция «Добавить модули» недоступна, вероятно, она была установлена вне Unity Hub. Пожалуйста, переустановите правильную версию Unity через Unity Hub.
</Callout>

## Получение фреймворка Basis

### Git

Вы можете напрямую [клонировать](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) ветки `developer` или `long-term-support` с https://github.com/BasisVR/Basis или [форкнуть](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo) в собственный локальный репозиторий. Проект Unity находится в подпапке `Basis` внутри клона (`Basis/Basis`), см. раздел [Открытие проекта в Unity Hub](#opening-the-project-in-unity-hub) ниже.

### Прямое скачивание ZIP

Для тех, кто хочет обойтись без Git:

- Выберите выпадающее меню «Code» в правом верхнем углу, затем «Скачать ZIP».
- Распакуйте ZIP в любую папку. Архив распаковывается в папку с именем ветки, например `Basis-developer`.
- Добавьте находящуюся внутри неё подпапку `Basis` как существующий проект в Unity Hub, как описано в разделе [Открытие проекта в Unity Hub](#opening-the-project-in-unity-hub).

![Скачать ZIP с GitHub](/img/getting-started/3.png)

### Открытие проекта в Unity Hub [#opening-the-project-in-unity-hub]

Папка, которую вы клонировали или распаковали, содержит весь репозиторий Basis, а не только проект Unity. Проект Unity находится в подпапке `Basis` внутри неё, рядом с папками сервера и инструментов:

```text
Basis-developer/         распакованная папка (клон Git называется просто Basis)
├── Basis/               проект Unity: именно эту папку нужно добавить в Unity Hub
│   ├── Assets/
│   ├── Packages/
│   └── ProjectSettings/
├── Basis Server/
├── tools/
└── ...
```

- В Unity Hub откройте вкладку **Projects**, нажмите **Add** (**Open** в старых версиях Hub) и выберите **Add project from disk**.
- Перейдите в распакованную или клонированную папку, выберите вложенную папку `Basis` и подтвердите выбор.
- Проект появится в списке Unity Hub. Нажмите на него, чтобы открыть.

<Callout type="warn">
Правильная папка содержит `Assets`, `Packages` и `ProjectSettings`. Если вместо неё выбрать папку верхнего уровня (например `Basis-developer`), Unity Hub не распознает её как проект Unity.
</Callout>
